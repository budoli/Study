# Day 002 - 문장과 단어 세기

## 오늘의 목표

텍스트 파일을 읽고 줄 수, 빈 줄 제외 줄 수, 전체 단어 수, 줄별 단어 수를 계산한다.

## 배운 개념

| 개념 | 설명 |
| --- | --- |
| `splitlines()` | 문자열을 줄 단위 리스트로 나눈다. |
| `strip()` | 문자열 앞뒤의 공백과 줄바꿈을 제거한다. |
| `split()` | 문자열을 공백 기준으로 나누어 단어 리스트를 만든다. |
| `len()` | 리스트나 문자열의 길이를 구한다. |
| `enumerate()` | 반복하면서 순서 번호와 값을 함께 가져온다. |

## 작성한 코드

```python
from pathlib import Path

file_path = Path("data/sample_docs/day002.txt")
text = file_path.read_text(encoding="utf-8")

lines = text.splitlines()
non_empty_lines = [line for line in lines if line.strip()]

count = 0

for line in non_empty_lines:
    words = line.split()
    count += len(words)

print(f"전체 줄 수 : {len(lines)}")
print(f"빈 줄 제외 줄 수 : {len(non_empty_lines)}")
print(f"전체 단어 수 : {count}")

print("줄별 단어 수:")
for index, line in enumerate(non_empty_lines, start=1):
    words = line.split()
    print(f"{index}번째 줄: {len(words)}개")
```

## 핵심 정리

- `lines`는 줄들이 들어 있는 리스트이므로 줄 수는 `len(lines)`로 구한다.
- `non_empty_lines`는 빈 줄을 제외한 리스트이므로 개수는 `len(non_empty_lines)`로 구한다.
- `words`는 한 줄을 단어로 나눈 리스트이므로 단어 수는 `len(words)`로 구한다.
- `count`는 이미 계산된 숫자이므로 `len(count)`를 쓰지 않는다.
- 줄 번호가 필요할 때는 `enumerate(non_empty_lines, start=1)`를 사용한다.

## 헷갈렸던 점

| 잘못된 코드 | 이유 | 수정 |
| --- | --- | --- |
| `print(lines)` | 줄 개수가 아니라 리스트 전체가 출력된다. | `print(len(lines))` |
| `print(non_empty_lines)` | 빈 줄 제외 줄 개수가 아니라 리스트 전체가 출력된다. | `print(len(non_empty_lines))` |
| `len(count)` | `count`는 숫자라서 길이를 구할 수 없다. | `count` |
| `print(words)` | 단어 개수가 아니라 단어 리스트가 출력된다. | `len(words)` |
