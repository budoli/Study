# Day 019 - overlap이 있는 chunk 만들기

## 오늘의 목표

긴 문서를 chunk로 나누되, chunk 사이에 일부 글자가 겹치도록 overlap을 적용한다.

## Overlap

Overlap은 인접한 chunk 사이에 일부 내용을 겹치게 넣는 방식이다.

```text
chunk_size = 100
overlap = 20
step = 80

Chunk 1: 0 ~ 100
Chunk 2: 80 ~ 180
Chunk 3: 160 ~ 260
```

이렇게 하면 앞 chunk의 마지막 20글자가 다음 chunk의 앞부분에 다시 포함된다.

## 배운 개념

| 개념 | 설명 |
| --- | --- |
| `chunk_size` | chunk 하나의 최대 길이이다. |
| `overlap` | 다음 chunk와 겹칠 글자 수이다. |
| `step` | 다음 chunk 시작 위치까지 이동할 간격이다. |
| `(start, end, chunk)` | chunk의 시작 위치, 끝 위치, 내용을 함께 저장한 튜플이다. |
| `enumerate()` | chunk 번호와 값을 함께 반복할 때 사용한다. |

## 작성한 코드

```python
"""Day 019 - Chunk overlap."""

from pathlib import Path


def main():
    file_path = Path("data/sample_docs/day019.txt")
    text = file_path.read_text(encoding="utf-8")

    chunk_size = 100
    overlap = 20

    chunks = []
    step = chunk_size - overlap

    print(f"chunk_size = {chunk_size}")
    print(f"overlap = {overlap}")

    for start in range(0, len(text), step):
        end = start + chunk_size
        chunk = text[start:end]

        if chunk:
            chunks.append((start, end, chunk))

    print(f"전체 Chunk 개수: {len(chunks)}")

    for index, (start, end, chunk) in enumerate(chunks, start=1):
        print(f"Chunk {index}")
        print(f"시작 위치: {start}")
        print(f"끝 위치: {end}")
        print(f"길이: {len(chunk)}")
        print("내용:")
        print(chunk)

if __name__ == "__main__":
    main()
```

## 핵심 정리

- `step = chunk_size - overlap`으로 다음 chunk의 시작 위치를 계산한다.
- `chunk_size = 100`, `overlap = 20`이면 `step = 80`이다.
- 시작 위치가 `0, 80, 160, 240...`처럼 이동한다.
- chunk 내용만 저장하면 시작/끝 위치를 출력하기 어렵다.
- 그래서 `chunks.append((start, end, chunk))`처럼 튜플로 저장한다.
- 출력할 때는 `for index, (start, end, chunk) in enumerate(...)` 구조를 사용한다.

## 실행 결과 핵심

```text
Chunk 1
시작 위치: 0
끝 위치: 100
길이: 100

Chunk 2
시작 위치: 80
끝 위치: 180
길이: 100

Chunk 3
시작 위치: 160
끝 위치: 260
길이: 84

Chunk 4
시작 위치: 240
끝 위치: 340
길이: 4
```

시작 위치가 80씩 증가하므로 20글자 overlap이 적용된 상태이다.

## 헷갈렸던 점

| 잘못된 코드 | 문제 | 수정 |
| --- | --- | --- |
| `chunks.append(chunk)` | 시작 위치와 끝 위치를 잃어버린다. | `chunks.append((start, end, chunk))` |
| `for index, (start, end, index)` | chunk 번호 변수와 내용 변수가 충돌한다. | `for index, (start, end, chunk)` |
| `len(chunk)`가 마지막 chunk만 봄 | 반복문에서 chunk를 제대로 받지 않았다. | 튜플에서 `chunk`를 꺼내 반복 |

## 개선 포인트

마지막 chunk가 너무 짧으면 제외할 수도 있다.

```python
if len(chunk) >= 20:
    chunks.append((start, end, chunk))
```

하지만 이번 과제에서는 마지막 chunk가 짧아도 허용했다.

출력 가독성을 위해 chunk 사이에 빈 줄을 넣을 수도 있다.

```python
print()
```

## RAG와의 연결

RAG에서 overlap은 chunk 경계에서 문맥이 끊기는 문제를 줄인다.

```text
질문과 관련된 정보가 chunk 경계에 걸쳐 있을 때
overlap이 있으면 검색될 가능성이 높아진다.
```

다만 overlap이 너무 크면 같은 내용이 여러 chunk에 반복되어 저장 공간과 검색 비용이 늘어난다.
