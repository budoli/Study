# Day 005 - 불용어 제거

## 오늘의 목표

텍스트에서 분석에 크게 도움이 되지 않는 단어를 제거하고, 남은 단어의 빈도를 계산한다.

## 배운 개념

| 개념 | 설명 |
| --- | --- |
| 불용어 | 자주 나오지만 분석 의미가 약한 단어이다. |
| `set` | 중복 없는 값 모음이며 포함 여부 확인이 빠르다. |
| 리스트 컴프리헨션 | 리스트를 간결하게 필터링하거나 변환할 수 있다. |
| `Counter` | 리스트 안의 값이 몇 번 등장했는지 계산한다. |
| `most_common()` | 빈도 높은 항목을 순서대로 가져온다. |

## 작성한 코드

```python
from pathlib import Path
from collections import Counter

file_path = Path("data/sample_docs/day005.txt")
text = file_path.read_text(encoding="utf-8")
normalize_text = (
    text.lower().replace(",", "").replace(".", "").replace("!", "").replace("?", "")
)
text_list = normalize_text.split()

stopwords = {"is", "are", "and", "the", "for"}

filter_word = [word for word in text_list if word not in stopwords]

count = Counter(filter_word)

print("불용어 제거 전 단어 리스트:")
print(text_list)

print("불용어 제거 후 단어 리스트:")
print(filter_word)

top_filter = count.most_common(5)

print("불용어 제거 후 단어 빈도 상위 5개:")
for word, count in top_filter:
    print(f"{word}: {count}")
```

## 핵심 정리

- 불용어는 문장에는 자주 나오지만 검색이나 분석에서 중요한 의미가 약한 단어이다.
- `is`, `and`, `for`, `the` 같은 단어를 제거하면 중요한 단어가 더 잘 보인다.
- 불용어는 리스트보다 `set`으로 만드는 것이 일반적이다.
- `word not in stopwords`는 현재 단어가 불용어 목록에 없는지 확인한다.
- 불용어 제거 후 `Counter`를 적용해야 의미 있는 단어의 빈도를 볼 수 있다.

## 리스트 컴프리헨션 이해

```python
filter_word = [word for word in text_list if word not in stopwords]
```

위 코드는 아래 코드와 같은 의미이다.

```python
filter_word = []

for word in text_list:
    if word not in stopwords:
        filter_word.append(word)
```

즉, `text_list`의 단어를 하나씩 확인하면서 불용어가 아닌 단어만 새 리스트에 담는다.

## 헷갈릴 수 있는 점

| 코드 | 의미 |
| --- | --- |
| `stopwords = {"is", "and"}` | 제거할 단어 집합을 만든다. |
| `word not in stopwords` | 단어가 불용어가 아닌지 확인한다. |
| `Counter(filter_word)` | 불용어 제거 후 단어 빈도를 계산한다. |
| `count.most_common(5)` | 가장 많이 나온 단어 5개를 가져온다. |
| `for word, count in top_filter` | `(단어, 횟수)`를 바로 분리해서 받는다. |
