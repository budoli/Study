# Day 004 - 자주 나온 단어 찾기

## 오늘의 목표

텍스트 파일을 읽고 단어 빈도를 계산한 뒤, 가장 자주 나온 단어 상위 5개를 출력한다.

## 배운 개념

| 개념 | 설명 |
| --- | --- |
| `Counter` | 리스트 안의 값이 몇 번 나왔는지 세는 도구이다. |
| `most_common()` | 가장 많이 등장한 항목을 빈도순으로 가져온다. |
| `lower()` | 대소문자 차이로 단어가 따로 세어지는 것을 막는다. |
| `replace()` | 구두점을 제거할 때 사용할 수 있다. |
| `split()` | 정규화된 텍스트를 단어 리스트로 나눈다. |

## 작성한 코드

```python
from pathlib import Path
from collections import Counter

file_path = Path("data/sample_docs/day004.txt")

text = file_path.read_text(encoding="utf-8")

normalize_text = text.lower().replace(",", "").replace(".", "").replace("!", "").replace("?", "")

text_list = normalize_text.split()

count = Counter(text_list)

top_word = count.most_common(5)

print("단어 빈도 상위 5개:")
for i in range(0, 5):
    print(f"{top_word[i][0]}: {top_word[i][1]}")
```

## 핵심 정리

- 단어 빈도를 세기 전에는 먼저 텍스트를 정규화해야 한다.
- `Python`과 `python`을 같은 단어로 세려면 `lower()`를 사용한다.
- `RAG.`와 `rag`를 같은 단어로 세려면 구두점을 제거해야 한다.
- `Counter(text_list)`는 단어 리스트를 받아 각 단어의 등장 횟수를 계산한다.
- `most_common(5)`는 가장 많이 나온 단어 5개를 `(단어, 횟수)` 형태로 반환한다.

## 더 안전한 출력 방식

현재 코드는 단어 종류가 5개보다 적으면 에러가 날 수 있다.

```python
for i in range(0, 5):
    print(f"{top_word[i][0]}: {top_word[i][1]}")
```

더 안전하게는 `top_word`를 직접 반복하는 방식이 좋다.

```python
for word, count in top_word:
    print(f"{word}: {count}")
```

이 방식은 결과가 5개보다 적어도 에러가 나지 않는다.

## 헷갈릴 수 있는 점

| 코드 | 의미 |
| --- | --- |
| `Counter(text_list)` | 단어 리스트에서 단어별 개수를 센다. |
| `count.most_common(5)` | 많이 나온 단어 5개를 가져온다. |
| `top_word[i][0]` | i번째 결과의 단어이다. |
| `top_word[i][1]` | i번째 결과의 등장 횟수이다. |
| `for word, count in top_word` | `(단어, 횟수)`를 바로 나누어 받는다. |
