# Day 008 - Jaccard 유사도로 문서 비교하기

## 오늘의 목표

문서를 단어 집합으로 바꾸고, Jaccard 유사도를 사용해서 문서 간 비슷한 정도를 계산한다.

## Jaccard 유사도

```text
Jaccard similarity = 교집합 개수 / 합집합 개수
```

두 문서가 공유하는 단어가 많을수록 점수가 높아진다.

## 배운 개념

| 개념 | 설명 |
| --- | --- |
| `set` | 중복 없는 단어 집합을 만든다. |
| `&` | 두 집합의 교집합을 구한다. |
| `|` | 두 집합의 합집합을 구한다. |
| `sorted()` | 집합을 정렬된 리스트로 출력한다. |
| Jaccard 유사도 | 교집합 크기를 합집합 크기로 나눈 값이다. |

## 작성한 코드

```python
from pathlib import Path

def nomalized(text):
    return (
        text.lower()
        .replace(",", "")
        .replace(".", "")
        .replace("!", "")
        .replace("?", "")
        .split()
    )

def text_to_word_set(path):
    text = Path(path).read_text(encoding="utf-8")
    normalized_token = nomalized(text)
    return set(normalized_token)

def jaccard_similarity(setA, setB):
    intersection = setA & setB
    union = setA | setB

    if not union:
        return 0

    return len(intersection) / len(union)

unique_token_a = text_to_word_set("data/sample_docs/day008_doc1.txt")
unique_token_b = text_to_word_set("data/sample_docs/day008_doc2.txt")
unique_token_c = text_to_word_set("data/sample_docs/day008_doc3.txt")

print()
print("문서 A-B 비교")
print(f"교집합: {sorted(unique_token_a & unique_token_b)}")
print(f"합집합: {sorted(unique_token_a | unique_token_b)}")
print(f"Jaccard 유사도: {jaccard_similarity(unique_token_a, unique_token_b)}")

print()
print("문서 A-C 비교")
print(f"교집합: {sorted(unique_token_a & unique_token_c)}")
print(f"합집합: {sorted(unique_token_a | unique_token_c)}")
print(f"Jaccard 유사도: {jaccard_similarity(unique_token_a, unique_token_c)}")

print()
print("문서 B-C 비교")
print(f"교집합: {sorted(unique_token_b & unique_token_c)}")
print(f"합집합: {sorted(unique_token_b | unique_token_c)}")
print(f"Jaccard 유사도: {jaccard_similarity(unique_token_b, unique_token_c)}")
```

## 핵심 정리

- 문서 비교 전에 먼저 정규화가 필요하다.
- `set(normalized_token)`을 사용하면 중복 단어가 제거된다.
- Jaccard 유사도는 단어의 빈도는 보지 않고, 단어가 등장했는지만 본다.
- `unique_token_a & unique_token_b`는 두 문서에 모두 있는 단어를 구한다.
- `unique_token_a | unique_token_b`는 두 문서 중 하나라도 포함한 단어를 구한다.
- A-B 비교에서는 반드시 `jaccard_similarity(unique_token_a, unique_token_b)`처럼 서로 다른 문서를 넣어야 한다.

## 헷갈렸던 점

| 잘못된 코드 | 문제 | 수정 |
| --- | --- | --- |
| `jaccard_similarity(unique_token_b, unique_token_b)` | B 문서와 B 문서를 비교하므로 항상 1.0이 나온다. | `jaccard_similarity(unique_token_a, unique_token_b)` |
| `list(set_a & set_b)` | 출력 순서가 매번 보기 좋지 않을 수 있다. | `sorted(set_a & set_b)` |
| `list(set_a | set_b)` | 합집합 출력 순서가 정렬되지 않는다. | `sorted(set_a | set_b)` |
