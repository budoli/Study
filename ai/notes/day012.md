# Day 012 - 간단한 키워드 검색기

## 오늘의 목표

검색어가 문서에 몇 번 등장하는지 계산하고, 점수가 높은 문서부터 정렬해서 출력한다.

## 전체 흐름

```text
문서 읽기
-> 검색어 정규화
-> 문서 정규화
-> 검색어 등장 횟수 계산
-> 점수 0 초과 문서만 저장
-> 점수 높은 순서로 정렬
-> 검색 결과 출력
```

## 배운 개념

| 개념 | 설명 |
| --- | --- |
| 키워드 검색 | 검색어가 포함된 문서를 찾는 가장 단순한 검색 방식이다. |
| `count()` | 리스트 안에서 특정 값이 몇 번 등장하는지 센다. |
| ranking | 검색 결과에 점수를 매기고 높은 순서로 정렬하는 과정이다. |
| `sorted()` | 검색 결과를 점수 기준으로 정렬할 때 사용한다. |
| `lambda x: x[1]` | 튜플의 두 번째 값인 점수를 정렬 기준으로 사용한다. |

## 작성한 코드

```python
"""Day 012 - Simple keyword search."""

from pathlib import Path


def normalized(text):
    return (
        text.lower().replace(",", "").replace(".", "").replace("!", "").replace("?", "")
    )


def main():

    doc_path = [
        "data/sample_docs/day012_doc1.txt",
        "data/sample_docs/day012_doc2.txt",
        "data/sample_docs/day012_doc3.txt",
    ]

    documents = [Path(path).read_text(encoding="utf-8") for path in doc_path]

    query = "search"
    normalized_query = normalized(query)

    result = []

    for index, document in enumerate(documents, start=1):
        normalized_document = normalized(document)
        words = normalized_document.split()
        score = words.count(normalized_query)

        if score > 0:
            result.append((index, score, document))

    result = sorted(result, key=lambda x: x[1], reverse=True)

    print(f"검색어: {query}")
    print()

    print("검색결과:")
    for index, score, document in result:

        print(f"문서 {index} | 점수: {score}")
        print(document)


if __name__ == "__main__":
    main()
```

## 핵심 정리

- 검색어와 문서를 같은 방식으로 정규화해야 정확히 비교할 수 있다.
- `normalized(document).split()`으로 문서를 단어 리스트로 만든다.
- `words.count(normalized_query)`로 검색어 등장 횟수를 점수로 사용한다.
- 점수가 0인 문서는 검색 결과에서 제외한다.
- `result.append((index, score, document))`처럼 문서 번호, 점수, 원문을 함께 저장한다.
- 정렬은 출력 전에 해야 한다.

## 헷갈렸던 점

| 잘못된 코드 | 문제 | 수정 |
| --- | --- | --- |
| `normalized(documents)` | `documents`는 리스트라서 `.lower()`를 사용할 수 없다. | `normalized(document)` |
| 정렬 전에 출력 | 검색 결과가 점수순으로 보장되지 않는다. | `sorted()` 후 출력 |
| `print()`를 반복문 안에 너무 일찍 작성 | 결과 저장과 출력 흐름이 섞인다. | 먼저 `result`를 만들고 마지막에 출력 |

## 주요 코드 해석

```python
score = words.count(normalized_query)
```

문서 단어 리스트에서 검색어가 몇 번 등장하는지 계산한다.

```python
if score > 0:
    result.append((index, score, document))
```

검색어가 한 번 이상 등장한 문서만 결과에 저장한다.

```python
result = sorted(result, key=lambda x: x[1], reverse=True)
```

튜플의 두 번째 값인 점수를 기준으로 높은 순서로 정렬한다.
