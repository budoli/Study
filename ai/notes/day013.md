# Day 013 - 한국어 토큰화 맛보기

## 오늘의 목표

한국어 문장을 공백 기준으로 토큰화하고, 간단한 규칙으로 조사 제거를 시도한다.

## 전체 흐름

```text
파일 읽기
-> 공백 기준 토큰화
-> 구두점 제거
-> 토큰 끝의 조사 확인
-> 조사 제거
-> 단어 빈도 계산
```

## 배운 개념

| 개념 | 설명 |
| --- | --- |
| 공백 기준 토큰화 | `split()`으로 공백 기준 단어를 나누는 방식이다. |
| 조사 | 한국어 단어 뒤에 붙는 `은`, `는`, `이`, `가`, `을`, `를` 같은 요소이다. |
| `endswith()` | 문자열이 특정 글자로 끝나는지 확인한다. |
| `replace()` | 구두점을 제거할 때 사용한다. |
| `Counter` | 토큰 빈도를 계산한다. |

## 작성한 코드

```python
"""Day 013 - Korean tokenization."""
from pathlib import Path
from collections import Counter

def main():
    file_path = Path("data/sample_docs/day013.txt")
    text = file_path.read_text(encoding="utf-8")

    tab_token = text.split()

    particles = ["은", "는", "이", "가", "을", "를", "의", "에", "로", "으로"]

    particles_token = []

    for token in tab_token:
        token = token.replace(".", "")

        for particle in particles:
            if token.endswith(particle):
                token = token[:-len(particle)]
                break

        particles_token.append(token)

    particles_token_count = Counter(particles_token)
    particles_token_common = particles_token_count.most_common(5)

    print("원본 텍스트:")
    print(text)
    print()
    print("공백 기준 토큰:")
    print(tab_token)
    print()
    print(f"공백 기중 토큰 개수:{len(tab_token)}")
    print()
    print("조사 제거 후 토큰:")
    print(particles_token)
    print()
    print(f"조사 제거 후 토큰 개수: {len(particles_token)}")
    print()
    print("단어 빈도 상위 5개:")
    for word, count in particles_token_common:
        print(f"{word}: {count}")

if __name__ == "__main__":
    main()
```

## 핵심 정리

- 영어와 달리 한국어는 조사와 어미가 단어에 붙어 있어서 단순 `split()`만으로는 부족하다.
- `처리는`은 공백 기준으로 보면 하나의 토큰이지만, 실제로는 `처리 + 는`으로 볼 수 있다.
- `token.endswith(particle)`로 토큰이 특정 조사로 끝나는지 확인할 수 있다.
- `token[:-len(particle)]`로 끝에 붙은 조사 길이만큼 잘라낼 수 있다.
- 규칙 기반 조사 제거는 완벽하지 않다.

## 헷갈렸던 점

| 코드 | 문제 | 수정 |
| --- | --- | --- |
| `token.replace(".", "")` | 문자열은 직접 바뀌지 않고 변경된 값을 반환한다. | `token = token.replace(".", "")` |
| `text.replace(particle, "")` | 전체 문서에서 모든 글자를 제거해 의도치 않은 결과가 생길 수 있다. | 토큰마다 `endswith()`로 끝 조사만 확인한다. |
| `Counter(particles_token)` 전 2차원 리스트 | `Counter`에는 단어 리스트가 들어가야 한다. | 1차원 토큰 리스트를 만든다. |

## 규칙 기반 방식의 한계

이번 방식은 형태소 분석기가 아니기 때문에 어색한 결과가 생긴다.

| 원본 | 결과 | 이유 |
| --- | --- | --- |
| `분석하는` | `분석하` | 끝 글자 `는`을 조사로 보고 제거했기 때문이다. |
| `찾는` | `찾` | 실제로는 어미인데 조사처럼 제거됐다. |
| `바탕으로` | `바탕으` | `로`만 제거되어 어색해졌다. |

이 한계 때문에 실전 한국어 NLP에서는 Kiwi, KoNLPy 같은 형태소 분석기를 사용한다.
