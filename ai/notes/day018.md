# Day 018 - 긴 문서를 chunk로 자르기

## 오늘의 목표

긴 문서를 일정 글자 수 기준으로 나누어 chunk 리스트를 만든다.

## Chunking

Chunking은 긴 문서를 작은 조각으로 나누는 작업이다.

RAG에서는 긴 문서를 통째로 검색하지 않고, 질문과 관련 있는 chunk만 찾아서 사용한다.

```text
긴 문서
-> chunk 1
-> chunk 2
-> chunk 3
```

## 배운 개념

| 개념 | 설명 |
| --- | --- |
| chunk | 긴 문서를 나눈 작은 조각이다. |
| `chunk_size` | chunk 하나의 최대 길이를 정하는 값이다. |
| `range(start, end, step)` | 일정 간격으로 숫자를 증가시키며 반복한다. |
| slicing | 문자열의 일부를 잘라낼 때 사용한다. |
| `len(chunk)` | 각 chunk의 실제 길이를 구한다. |

## 작성한 코드

```python
"""Day 018 - Document chunking."""
from pathlib import Path

def main():

    file_path = Path("data/sample_docs/day018.txt")
    text = file_path.read_text(encoding="utf-8")

    chunk_size = 100

    chunks = []

    for i in range(0, len(text), 100):
        end = i + chunk_size
        chunk = text[i:end]
        chunks.append(chunk)

    print(f"전체 chunk 개수: {len(chunks)}")
    print()
    for index, text in enumerate(chunks, start=1):
        print(f"Chunk {index}")
        print(f"길이: {len(text)}")
        print("내용:")
        print(text)

if __name__ == "__main__":
    main()
```

## 핵심 정리

- 전체 문서 길이는 `len(text)`로 구한다.
- `range(0, len(text), chunk_size)`는 0부터 문서 끝까지 `chunk_size`씩 이동한다.
- `text[i:end]`는 i 위치부터 end 전까지 문자열을 자른다.
- 마지막 chunk는 `chunk_size`보다 짧을 수 있다.
- 전체 chunk 개수는 `len(chunks)`로 구한다.
- 각 chunk의 길이는 고정값이 아니라 `len(chunk)`로 구해야 한다.

## 헷갈렸던 점

| 잘못된 코드 | 문제 | 수정 |
| --- | --- | --- |
| `len(chunk)`로 전체 개수 출력 | `chunk`는 마지막 조각 문자열이다. | `len(chunks)` |
| `for index, text in chunk` | 문자열을 글자 단위로 반복해서 unpack 오류가 난다. | `enumerate(chunks, start=1)` |
| `print(f"길이: {100}")` | 마지막 chunk도 100으로 출력된다. | `print(f"길이: {len(chunk)}")` |

## 실행 결과 핵심

```text
전체 chunk 개수: 3

Chunk 1
길이: 100

Chunk 2
길이: 100

Chunk 3
길이: 49
```

마지막 chunk는 남은 글자만 들어가기 때문에 100보다 짧다.

## 개선 포인트

반복문에서 `text`라는 이름을 다시 쓰면 원문 전체 변수와 헷갈릴 수 있다.

현재:

```python
for index, text in enumerate(chunks, start=1):
```

개선:

```python
for index, chunk in enumerate(chunks, start=1):
    print(f"Chunk {index}")
    print(f"길이: {len(chunk)}")
    print("내용:")
    print(chunk)
```

또 반복문에서도 직접 `100`을 쓰기보다 `chunk_size` 변수를 쓰는 편이 좋다.

```python
for i in range(0, len(text), chunk_size):
```

## 한계

글자 수 기준 chunking은 단순하지만 한계가 있다.

- 문장이 중간에 잘릴 수 있다.
- 단어가 중간에 잘릴 수 있다.
- 의미 단위가 깨질 수 있다.
- 앞뒤 chunk 사이의 문맥이 끊길 수 있다.

이 문제를 줄이기 위해 다음 단계에서는 overlap을 사용한다.
