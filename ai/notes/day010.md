# Day 010 - TF-IDF로 문서 키워드 뽑기

## 오늘의 목표

세 문서를 읽고 `TfidfVectorizer`를 사용해 각 문서에서 중요한 단어 상위 5개를 뽑는다.

## TF-IDF

TF-IDF는 단어의 단순 빈도만 보는 것이 아니라, 특정 문서에서 상대적으로 중요한 단어를 찾는 방식이다.

```text
TF-IDF = 문서 안에서 자주 나오고, 다른 문서에는 덜 나오는 단어를 높게 평가
```

## 배운 개념

| 개념 | 설명 |
| --- | --- |
| `TfidfVectorizer` | 문서 리스트를 TF-IDF 벡터로 바꾸는 도구이다. |
| `fit_transform()` | 문서들을 보고 vocabulary를 만든 뒤 TF-IDF 행렬로 변환한다. |
| `get_feature_names_out()` | TF-IDF 벡터의 각 칸이 어떤 단어인지 가져온다. |
| `toarray()` | sparse matrix를 눈으로 보기 쉬운 배열로 바꾼다. |
| `zip()` | 단어와 점수를 한 쌍으로 묶는다. |
| `sorted()` | 점수 높은 순서로 정렬할 때 사용한다. |

## 작성한 코드

```python
from pathlib import Path
from sklearn.feature_extraction.text import TfidfVectorizer

file_path = [
    "data/sample_docs/day010_doc1.txt",
    "data/sample_docs/day010_doc2.txt",
    "data/sample_docs/day010_doc3.txt"
]

documents = [
    Path(path).read_text(encoding="utf-8")
    for path in file_path
]

vectorizer = TfidfVectorizer()
X = vectorizer.fit_transform(documents)
feature_word = vectorizer.get_feature_names_out()

print("Vocabulary:")
print(feature_word)
print()

for index, row in enumerate(X.toarray(), start=1):
    scores = list(zip(feature_word, row))
    top_scores = sorted(scores, key=lambda x: x[1], reverse=True)[:5]
    print(f"문서 {index} TF-IDF 상위 5개:")
    for word, score in top_scores:
        print(f"{word}: {score:.4f}")
```

## 핵심 정리

- Day 009에서는 직접 vocabulary와 BoW 벡터를 만들었다.
- Day 010에서는 `TfidfVectorizer`가 vocabulary 생성과 TF-IDF 계산을 대신한다.
- `fit_transform(documents)`는 문서 리스트를 입력받아 TF-IDF 행렬을 만든다.
- `feature_word`는 벡터의 각 위치가 어떤 단어인지 알려준다.
- `X.toarray()`를 사용하면 문서별 점수 배열을 순회할 수 있다.
- `zip(feature_word, row)`로 단어와 점수를 묶을 수 있다.
- `sorted(..., key=lambda x: x[1], reverse=True)`로 점수 높은 단어를 먼저 볼 수 있다.

## Day 009와 비교

| 구분 | Day 009 BoW | Day 010 TF-IDF |
| --- | --- | --- |
| 벡터 값 | 단어 등장 횟수 | 단어 중요도 점수 |
| vocabulary 생성 | 직접 생성 | `TfidfVectorizer`가 생성 |
| 정규화 | 직접 구현 | 기본적으로 소문자 변환 처리 |
| 출력 | 정수 벡터 | 소수점 점수 |
| 의미 | 얼마나 자주 나왔는가 | 얼마나 중요한가 |

```text

```

```python
vectorizer = TfidfVectorizer()
X = vectorizer.fit_transform(documents)
feature_word = vectorizer.get_feature_names_out()

```

## 헷갈릴 수 있는 점

| 코드 | 의미 |
| --- | --- |
| `TfidfVectorizer()` | TF-IDF 변환기를 만든다. |
| `fit_transform(documents)` | 문서들을 학습하고 벡터로 변환한다. |
| `get_feature_names_out()` | 단어 목록을 가져온다. |
| `X.toarray()` | 행렬을 배열로 바꾼다. |
| `zip(feature_word, row)` | 단어와 해당 문서의 점수를 묶는다. |
| `x[1]` | `(단어, 점수)` 쌍에서 점수를 의미한다. |
