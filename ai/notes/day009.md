# Day 009 - Bag of Words 만들기

## 오늘의 목표

여러 문서를 읽고 전체 단어 목록을 기준으로 각 문서를 숫자 벡터로 표현한다.

## Bag of Words

Bag of Words는 문서를 단어 빈도 벡터로 표현하는 방법이다.

예를 들어 vocabulary가 아래와 같고:

```text
['python', 'rag', 'text']
```

문서가 아래와 같다면:

```text
python python text
```

BoW 벡터는 아래처럼 표현된다.

```text
[2, 0, 1]
```

## 배운 개념

| 개념 | 설명 |
| --- | --- |
| vocabulary | 전체 문서에 등장한 고유 단어 목록이다. |
| BoW 벡터 | vocabulary 기준으로 각 단어가 몇 번 나왔는지 나타낸 숫자 리스트이다. |
| `Counter` | 문서 안의 단어 빈도를 계산한다. |
| `sorted()` | vocabulary 순서를 고정한다. |
| 벡터화 | 텍스트를 숫자 리스트로 바꾸는 과정이다. |

## 작성한 코드

```python
from pathlib import Path
from collections import Counter

def normalize(text):
    return (
        text.lower()
        .replace(",", "")
        .replace(".", "")
        .replace("!", "")
        .replace("?", "")
        .split()
    )

def text_to_word_set(path):
    text = Path(path).read_text(encoding="utf-8")
    return normalize(text)

def make_bow(tokens, vocabulary):
    count = Counter(tokens)
    return [count[word] for word in vocabulary]

token_doc1 = text_to_word_set("data/sample_docs/day009_doc1.txt")
token_doc2 = text_to_word_set("data/sample_docs/day009_doc2.txt")
token_doc3 = text_to_word_set("data/sample_docs/day009_doc3.txt")

vocabulary = sorted(set(token_doc1 + token_doc2 + token_doc3))

print("Vocabulary:")
print(vocabulary)
print()
print("문서 1 BoW:")
print(make_bow(token_doc1, vocabulary))
print()
print("문서 2 BoW:")
print(make_bow(token_doc2, vocabulary))
print()
print("문서 3 BoW:")
print(make_bow(token_doc3, vocabulary))
```

## 핵심 정리

- BoW는 단어의 순서는 보지 않고 단어의 등장 횟수만 본다.
- 모든 문서는 같은 `vocabulary` 기준으로 벡터화해야 비교할 수 있다.
- `vocabulary = sorted(set(...))`를 사용하면 고유 단어 목록을 정렬된 순서로 만들 수 있다.
- `Counter(tokens)`는 한 문서 안에서 각 단어가 몇 번 나왔는지 계산한다.
- `[count[word] for word in vocabulary]`는 vocabulary 순서에 맞춰 빈도 벡터를 만든다.

## 주요 코드 해석

```python
vocabulary = sorted(set(token_doc1 + token_doc2 + token_doc3))
```

세 문서의 토큰을 모두 합친 뒤 중복을 제거하고 정렬한다.

```python
count = Counter(tokens)
return [count[word] for word in vocabulary]
```

문서 안의 단어 빈도를 계산하고, vocabulary에 있는 단어 순서대로 빈도 값을 꺼내 벡터를 만든다.

## 헷갈릴 수 있는 점

| 코드 | 의미 |
| --- | --- |
| `set(token_doc1 + token_doc2 + token_doc3)` | 세 문서 전체의 고유 단어를 만든다. |
| `sorted(...)` | vocabulary 순서를 고정한다. |
| `Counter(tokens)` | 한 문서의 단어 빈도를 계산한다. |
| `count[word]` | 해당 단어의 등장 횟수를 가져온다. |
| `[count[word] for word in vocabulary]` | 문서를 BoW 벡터로 변환한다. |
