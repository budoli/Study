# Day 017 - Top-K 문장 검색 만들기

## 오늘의 목표

질문과 의미적으로 가까운 문장을 cosine similarity 점수 기준으로 정렬하고, 상위 K개를 출력한다.

## 전체 흐름

```text
질문 작성
-> 검색 대상 문장 작성
-> 질문 임베딩
-> 문장 임베딩
-> cosine similarity 계산
-> 문장과 점수 묶기
-> 점수 높은 순서로 정렬
-> Top-K 출력
```

## 배운 개념

| 개념 | 설명 |
| --- | --- |
| Top-K 검색 | 점수가 높은 결과 K개만 가져오는 검색 방식이다. |
| 임베딩 검색 | 텍스트를 벡터로 바꾼 뒤 벡터 유사도로 검색하는 방식이다. |
| `cosine_similarity()` | 질문 벡터와 문장 벡터의 유사도를 계산한다. |
| ranking | 점수 높은 순서로 검색 결과를 정렬하는 과정이다. |
| `results[:top_k]` | 정렬된 결과에서 상위 K개만 가져온다. |

## 작성한 코드

```python
"""Day 017 - Top-K vector search."""
from sentence_transformers import SentenceTransformer
from sklearn.metrics.pairwise import cosine_similarity

def main():
    model = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")

    query = "How can I search relevant documents?"

    sentences = [
        "RAG retrieves relevant documents for a user question.",
        "Python is a programming language for automation.",
        "Search engines rank documents by relevance.",
        "NLP analyzes and processes human language.",
        "Vector search finds semantically similar text.",
        "Databases store structured business records.",
        "Question answering systems use retrieved context.",
    ]

    embeddings = model.encode(sentences)
    query_embedding = model.encode([query])

    similarities = cosine_similarity(embeddings, query_embedding)

    results = []

    for sentence, similar in zip(sentences, similarities):
        results.append((sentence, similar[0]))

    results = sorted(results, key=lambda x: x[1], reverse=True)

    print("질문:")
    print(query)
    print()
    print("Top 3 검색 결과:")
    for i in range(0, 3):
        print(f"{i+1}. {results[i][0]}")
        print(f"유사도: {results[i][1]:.4f}")

if __name__ == "__main__":
    main()
```

## 핵심 정리

- Day 016은 가장 유사한 문장 하나를 찾았다.
- Day 017은 가장 유사한 문장 여러 개를 Top-K로 가져온다.
- RAG에서는 보통 질문과 가까운 문서 조각 여러 개를 가져와 context로 사용한다.
- `results`에는 `(문장, 점수)` 튜플을 저장한다.
- `sorted(..., reverse=True)`로 점수 높은 순서로 정렬한다.
- 정렬된 결과의 앞부분이 가장 관련 있는 결과이다.

## 실행 결과 핵심

```text
Top 3 검색 결과:
1. Search engines rank documents by relevance.
유사도: 0.6149
2. RAG retrieves relevant documents for a user question.
유사도: 0.5362
3. Vector search finds semantically similar text.
유사도: 0.4838
```

질문이 `search relevant documents`에 가까워서 검색, RAG, 벡터 검색 관련 문장이 상위에 나왔다.

## RAG와의 연결

Top-K 검색은 RAG의 Retriever와 거의 같은 구조이다.

```text
사용자 질문
-> 질문 임베딩
-> 문서 조각 임베딩과 비교
-> 점수 높은 조각 Top-K 선택
-> 선택된 조각을 LLM context로 전달
```

즉, Day 017의 문장 리스트는 나중에 RAG에서 chunk 리스트가 된다.

## 헷갈릴 수 있는 점

| 코드 | 의미 |
| --- | --- |
| `model.encode(sentences)` | 검색 대상 문장들을 임베딩한다. |
| `model.encode([query])` | 질문 하나를 임베딩한다. |
| `cosine_similarity(embeddings, query_embedding)` | 각 문장과 질문의 유사도를 계산한다. |
| `similar[0]` | 2차원 결과에서 실제 점수를 꺼낸다. |
| `results[i][0]` | i번째 결과의 문장이다. |
| `results[i][1]` | i번째 결과의 유사도 점수이다. |

## 개선 포인트

현재는 `3`을 직접 사용했다.

```python
for i in range(0, 3):
```

아래처럼 `top_k` 변수로 빼면 나중에 검색 결과 개수를 쉽게 바꿀 수 있다.

```python
top_k = 3

for i in range(top_k):
    print(f"{i+1}. {results[i][0]}")
    print(f"유사도: {results[i][1]:.4f}")
```

또는 slicing을 사용할 수 있다.

```python
top_results = results[:top_k]

for rank, (sentence, score) in enumerate(top_results, start=1):
    print(f"{rank}. {sentence}")
    print(f"유사도: {score:.4f}")
```
