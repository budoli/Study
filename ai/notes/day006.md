# Day 006 - 텍스트를 토큰으로 나누기

## 오늘의 목표

텍스트를 기본 토큰과 정규화 토큰으로 나누어 비교하고, 중복을 제거한 고유 토큰 목록을 만든다.

## 배운 개념

| 개념 | 설명 |
| --- | --- |
| 토큰 | 텍스트를 분석하기 위해 나눈 단위이다. |
| 기본 토큰 | 원본 텍스트를 그대로 `split()`한 결과이다. |
| 정규화 토큰 | 소문자 변환과 구두점 제거를 거친 뒤 나눈 토큰이다. |
| `set()` | 중복을 제거할 때 사용한다. |
| `sorted()` | 값을 정렬된 리스트로 바꾼다. |

## 작성한 코드

```python
from pathlib import Path
from collections import Counter

file_path = Path("data/sample_docs/day006.txt")
text = file_path.read_text(encoding="utf-8")

basics_token = text.split()
normalized_token = (
    text.lower()
    .replace(",", "")
    .replace(".", "")
    .replace("!", "")
    .replace("?", "")
    .split()
)

unique_token = sorted(set(normalized_token))

print("원본 텍스트:")
print(text)
print()
print("기본 토큰:")
print(basics_token)
print()
print("정규화 토큰:")
print(normalized_token)
print()
print(f"기본 토큰 개수: {len(basics_token)}")
print(f"정규화 토큰 개수: {len(normalized_token)}")
print()
print("고유 토큰:")
print(unique_token)
print()
print(f"고유 토큰 개수: {len(unique_token)}")
```

## 핵심 정리

- `split()`은 공백, 줄바꿈, 탭을 기준으로 텍스트를 나눈다.
- 기본 토큰에서는 `Python,`, `PYTHON!`, `Python`이 서로 다른 토큰으로 취급된다.
- 정규화 후에는 대소문자와 구두점 차이가 사라져 `python` 하나로 통일된다.
- `set(normalized_token)`은 중복 토큰을 제거한다.
- `sorted(set(normalized_token))`은 고유 토큰을 보기 좋게 정렬한다.

## 헷갈릴 수 있는 점

| 코드 | 의미 |
| --- | --- |
| `text.split()` | 원본 텍스트를 그대로 토큰화한다. |
| `text.lower().replace(...).split()` | 정규화 후 토큰화한다. |
| `set(normalized_token)` | 중복 없는 토큰 묶음을 만든다. |
| `sorted(set(normalized_token))` | 중복 제거 후 정렬된 리스트를 만든다. |
| `len(unique_token)` | 고유 토큰 개수를 구한다. |
