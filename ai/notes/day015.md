# Day 015 - 문장을 임베딩 벡터로 바꾸기

## 오늘의 목표

문장 5개를 `SentenceTransformer` 모델로 임베딩하고, 문장이 숫자 벡터로 바뀌는 결과를 확인한다.

## 임베딩

임베딩은 텍스트를 의미를 담은 숫자 벡터로 바꾸는 방법이다.

```text
문장 -> 숫자 벡터
```

TF-IDF는 단어 일치와 빈도 기반 표현이고, 임베딩은 문장의 의미를 벡터 공간에 표현한다.

## 배운 개념

| 개념 | 설명 |
| --- | --- |
| `SentenceTransformer` | 문장 임베딩 모델을 불러오는 클래스이다. |
| `model.encode()` | 문장 리스트를 임베딩 벡터로 변환한다. |
| `numpy.ndarray` | 임베딩 결과가 담기는 배열 타입이다. |
| `shape` | 배열의 크기 정보를 보여준다. |
| 벡터 길이 | 한 문장이 몇 개의 숫자로 표현되는지 나타낸다. |

## 작성한 코드

```python
"""Day 015 - Sentence embedding."""
from sentence_transformers import SentenceTransformer

def main():

    model = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")

    sentences = [
        "Python is useful for data analysis.",
        "NLP processes human language.",
        "RAG retrieves relevant documents.",
        "Search systems find useful information.",
        "Machine learning uses numerical vectors.",
    ]

    embeddings = model.encode(sentences)
    
    print("임베딩 타입:")
    print(type(embeddings))
    print()
    print("임베딩 shape:")
    print(embeddings.shape)
    print()
    print("첫 번째 문장 임베딩 앞 10개:")
    print(embeddings[0][:10])
    print()
    print("문장별 벡터 길이:")
    for index, text in enumerate(embeddings, start=0):
        print(sentences[index])
        print(f"벡터 길이: {len(text)}")
        print()


if __name__ == "__main__":
    main()
```

## 실행 결과 핵심

```text
임베딩 타입:
<class 'numpy.ndarray'>

임베딩 shape:
(5, 384)
```

의미:

```text
5 = 문장 개수
384 = 각 문장을 표현하는 벡터 차원 수
```

즉, 문장 5개가 각각 384개의 숫자로 표현됐다.

## 핵심 정리

- `SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")`로 임베딩 모델을 불러온다.
- `model.encode(sentences)`는 문장 리스트 전체를 한 번에 벡터로 바꾼다.
- 결과는 `numpy.ndarray`이다.
- `embeddings.shape`를 보면 전체 문장 개수와 벡터 차원을 확인할 수 있다.
- `embeddings[0][:10]`은 첫 번째 문장 벡터의 앞 10개 숫자만 보여준다.
- 모든 문장은 같은 길이의 벡터로 변환된다.

## TF-IDF와 임베딩 비교

| 구분 | TF-IDF | Sentence Embedding |
| --- | --- | --- |
| 기준 | 단어 빈도와 문서별 중요도 | 문장의 의미 |
| 벡터 길이 | vocabulary 크기에 따라 달라짐 | 모델이 정한 고정 차원 |
| 단어 변형 처리 | 약함 | 상대적으로 강함 |
| 의미 유사도 | 제한적 | 더 잘 표현 가능 |
| 예시 | `document`와 `documents`를 다르게 볼 수 있음 | 의미가 비슷하면 가까울 수 있음 |

## 헷갈릴 수 있는 점

| 코드 | 의미 |
| --- | --- |
| `model.encode(sentences)` | 여러 문장을 한 번에 임베딩한다. |
| `embeddings[0]` | 첫 번째 문장의 전체 벡터이다. |
| `embeddings[0][:10]` | 첫 번째 문장 벡터의 앞 10개 값이다. |
| `embeddings.shape` | 전체 배열 크기이다. |
| `len(embedding)` | 한 문장 벡터의 길이이다. |

## 개선 포인트

현재 반복문도 정상 동작하지만, `zip()`을 쓰면 문장과 임베딩을 더 자연스럽게 묶을 수 있다.

```python
for sentence, embedding in zip(sentences, embeddings):
    print(sentence)
    print(f"벡터 길이: {len(embedding)}")
```
