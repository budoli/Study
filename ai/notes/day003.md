# Day 003 - 구두점 제거와 정규화

## 오늘의 목표

텍스트 파일을 읽고 대문자를 소문자로 바꾸며, 구두점을 제거한 뒤 정규화된 단어 리스트를 만든다.

## 배운 개념

| 개념 | 설명 |
| --- | --- |
| `lower()` | 문자열의 대문자를 소문자로 바꾼다. |
| `replace()` | 문자열 안의 특정 문자를 다른 문자로 바꾼다. |
| `strip()` | 문자열 앞뒤 공백과 줄바꿈을 제거한다. |
| `split()` | 문자열을 공백 기준으로 나누어 단어 리스트를 만든다. |
| 정규화 | 텍스트를 분석하기 쉬운 형태로 통일하는 작업이다. |

## 작성한 코드

```python
from pathlib import Path

file_path = Path("data/sample_docs/day003.txt")
text = file_path.read_text(encoding="utf-8")
lines = text.splitlines()
no_empty_line = [line for line in lines if line.strip()]

new_text = text.lower().replace(",", "").replace(".", "").replace("!", "").replace("?", "")
new_lines = new_text.splitlines()
no_empty_new_line = [new_line for new_line in new_lines if new_line.strip()]
new_normalized_words = new_text.split()

print("원본 텍스트:")
print(text)
print()
print("정규화된 텍스트:")
print(new_text)
print()

count = 0
for line in no_empty_line:
    words = line.split()
    count += len(words)

new_count = 0
for new_line in no_empty_new_line:
    new_words = new_line.split()
    new_count += len(new_words)

print(f"정규화 전 단어 수: {count}")
print(f"정규화 후 단어 수: {new_count}")
print()
print("정규화 된 단어 리스트:")
print(new_normalized_words)
```

## 핵심 정리

- `lower()`는 영어 대문자와 소문자를 같은 단어로 취급하기 위해 사용한다.
- `replace(",", "")`처럼 빈 문자열로 바꾸면 해당 문자를 제거할 수 있다.
- 여러 구두점을 제거할 때는 `replace()`를 연속으로 사용할 수 있다.
- 전체 정규화 단어 리스트는 `new_text.split()`으로 만든다.
- 반복문 안의 `new_words`는 현재 줄의 단어만 담기 때문에 전체 단어 리스트가 아니다.

## 헷갈렸던 점

| 잘못된 코드 | 이유 | 수정 |
| --- | --- | --- |
| `print(new_words)` | 마지막 줄의 단어 리스트만 출력된다. | `print(new_normalized_words)` |
| `replace(",", "").replace(",", "")` | 같은 구두점을 두 번 제거한다. | 한 번만 사용한다. |
| 구두점 제거 전 단어만 보기 | `NLP,`와 `NLP`가 다르게 취급될 수 있다. | 정규화 후 `split()`한다. |
