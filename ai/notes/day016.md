# Day 016 - 임베딩으로 문장 유사도 계산하기

## 오늘의 목표

기준 문장과 여러 비교 문장을 임베딩한 뒤, cosine similarity로 의미적 유사도를 계산한다.

## 전체 흐름

```text
기준 문장 작성
-> 비교 문장 리스트 작성
-> 기준 문장 임베딩
-> 비교 문장 임베딩
-> cosine similarity 계산
-> 문장과 점수를 묶기
-> 점수 높은 순서로 정렬
-> 가장 유사한 문장 출력
```

## 배운 개념

| 개념 | 설명 |
| --- | --- |
| 문장 임베딩 | 문장을 의미를 담은 숫자 벡터로 바꾸는 방식이다. |
| `cosine_similarity()` | 두 벡터의 방향이 얼마나 비슷한지 계산한다. |
| `zip()` | 문장과 유사도 점수를 함께 묶는다. |
| `sorted()` | 점수 높은 순서로 결과를 정렬한다. |
| `results[0]` | 정렬 후 가장 점수가 높은 결과이다. |

## 작성한 코드

```python
"""Day 016 - Sentence similarity."""
from sentence_transformers import SentenceTransformer
from sklearn.metrics.pairwise import cosine_similarity

def main():
    model = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")

    query = "How can I find relevant documents?"

    sentences = [
        "RAG retrieves useful documents for a question.",
        "Python is used for data analysis.",
        "Search systems find relevant information.",
        "Machine learning trains models with data.",
        "NLP processes human language.",
    ]

    embeddings = model.encode(sentences)
    query_embeddings = model.encode([query])

    similarities = cosine_similarity(embeddings, query_embeddings)
    best_index = similarities.argmax()

    results = []
    for sentence, score in zip(sentences, similarities):
        results.append((sentence, score[0]))

    results = sorted(results, key=lambda x: x[1], reverse=True)

    print("기준 문장:")
    print(query)
    print()
    print("문장별 유사도:")
    print()
    for sentence, score in results:
        print(sentence)
        print(f"유사도: {score:.4f}")
    print("가장 유사한 문장:")
    print(results[0][0])
    print(f"유사도: {results[0][1]:.4f}")

if __name__ == "__main__":
    main()
```

## 핵심 정리

- 기준 문장은 `model.encode([query])`처럼 리스트로 감싸서 임베딩한다.
- 비교 문장들은 `model.encode(sentences)`로 한 번에 임베딩한다.
- `cosine_similarity(embeddings, query_embeddings)`는 각 문장과 기준 문장의 유사도를 계산한다.
- 결과는 2차원 형태이므로 각 점수는 `score[0]`으로 꺼냈다.
- 문장과 점수를 `(sentence, score)` 튜플로 묶어 `results`에 저장한다.
- `sorted(results, key=lambda x: x[1], reverse=True)`로 점수 높은 순서로 정렬한다.
- 정렬 후 `results[0]`이 가장 유사한 문장이다.

## 실행 결과 핵심

```text
Search systems find relevant information.
유사도: 0.5706

RAG retrieves useful documents for a question.
유사도: 0.4968
```

## 헷갈렸던 점

| 코드 | 의미 |
| --- | --- |
| `model.encode([query])` | 기준 문장 하나를 2차원 형태로 임베딩한다. |
| `model.encode(sentences)` | 비교 문장 여러 개를 임베딩한다. |
| `cosine_similarity(embeddings, query_embeddings)` | 각 비교 문장과 기준 문장의 유사도를 계산한다. |
| `score[0]` | 2차원 유사도 결과에서 실제 점수를 꺼낸다. |
| `x[1]` | `(문장, 점수)`에서 점수를 의미한다. |
| `results[0]` | 정렬 후 가장 유사한 결과이다. |

## 개선 포인트

현재는 정렬된 `results[0]`을 사용하므로 아래 변수는 없어도 된다.

```python
best_index = similarities.argmax()
```

또 검색 구조를 더 자연스럽게 쓰려면 기준 문장을 앞에 둘 수 있다.

```python
similarities = cosine_similarity(query_embeddings, embeddings)[0]
```

그러면 점수를 바로 1차원 배열로 다룰 수 있다.

```python
for sentence, score in zip(sentences, similarities):
    results.append((sentence, score))
```
