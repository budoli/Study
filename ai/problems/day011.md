## 문제

세 문서를 TF-IDF로 벡터화하고, 질문과 가장 가까운 문서를 cosine similarity로 찾으세요.

## 요구사항

1. `days/day011_tfidf_search/main.py`를 사용하세요.
2. 세 문서를 읽으세요.
3. 질문 문자열을 작성하세요.
4. 문서는 `fit_transform()`으로 벡터화하세요.
5. 질문은 `transform([query])`으로 벡터화하세요.
6. `cosine_similarity()`로 유사도를 계산하세요.
7. 문서별 유사도와 가장 유사한 문서를 출력하세요.

## 힌트

```python
doc_vectors = vectorizer.fit_transform(documents)
query_vector = vectorizer.transform([query])
similarities = cosine_similarity(query_vector, doc_vectors)[0]
```

## 완료 조건

- 문서 번호, 유사도, 문서 내용이 출력된다.
