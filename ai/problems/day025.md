# Day 025 - Context 구성하기

| Day | 주제 | 문제명 | 핵심 |

| 025 | RAG | Context 구성하기 | prompt context |

## 문제

검색된 chunk 목록을 하나의 context 문자열로 묶고, 질문과 함께 프롬프트를 구성하세요.

## 요구사항

1. `days/day025_context_builder/main.py`를 사용하세요.
2. 검색 결과 chunk 목록을 준비하세요.
3. `build_context(results)` 함수를 만드세요.
4. `build_prompt(query, context)` 함수를 만드세요.
5. context에는 source와 chunk_id도 포함하세요.
6. 최종 프롬프트를 출력하세요.

## 출력 예시

```text
최종 프롬프트:
Context:
[source=data/sample_docs/doc1.txt, chunk_id=1]
RAG는 검색된 문서를 바탕으로 답변합니다.

Question:
RAG는 어떻게 답변하나요?
```

## 힌트

```python
context = "\n\n".join([item["text"] for item in results])
prompt = f"Context:\n{context}\n\nQuestion:\n{query}"
```

## 완료 조건

- 검색 결과가 답변 생성용 prompt context로 변환된다.
