# Day 007 - 기본 텍스트 분석기

| Day | 주제 | 문제명 | 핵심 |
| --- | --- | --- | --- |
| 007 | 미니과제 | 기본 텍스트 분석기 | file, count |

## 문제

Day 001~006에서 배운 내용을 합쳐 기본 텍스트 분석기를 만드세요.

## 요구사항

1. `days/day007_text_analyzer/main.py`를 사용하세요.
2. `data/sample_docs/day007.txt`를 읽으세요.
3. 원본 텍스트를 출력하세요.
4. 전체 줄 수와 빈 줄 제외 줄 수를 출력하세요.
5. 기본 토큰 개수, 정규화 토큰 개수, 고유 토큰 개수를 출력하세요.
6. 단어 빈도 상위 5개를 출력하세요.
7. 불용어 제거 후 단어 빈도 상위 5개를 출력하세요.

## 입력 예시

```text
Python is useful for NLP.
Python is useful for RAG.

NLP uses text processing.
RAG uses retrieval and generation.
Text processing is important for search.
```

## 출력 예시

```text
기본 분석:
전체 줄 수: 5
빈 줄 제외 줄 수: 4
기본 토큰 개수: 22
정규화 토큰 개수: 22
고유 토큰 개수: 12

단어 빈도 상위 5개:
is: 3
for: 3
python: 2
useful: 2
nlp: 2

불용어 제거 후 단어 빈도 상위 5개:
python: 2
useful: 2
nlp: 2
rag: 2
uses: 2
```

## 완료 조건

- 파일 읽기, 정규화, 토큰화, 빈도 분석, 불용어 제거가 하나의 흐름으로 연결된다.
