## 문제

한국어 텍스트를 공백 기준으로 토큰화하고, 간단한 조사 제거를 시도하세요.

## 요구사항

1. `days/day013_korean_tokenization/main.py`를 사용하세요.
2. `data/sample_docs/day013.txt`를 읽으세요.
3. 공백 기준 토큰 리스트와 개수를 출력하세요.
4. 조사 목록을 직접 만드세요.
5. `endswith()`로 토큰 끝의 조사를 확인하세요.
6. 조사 제거 후 토큰 리스트와 개수를 출력하세요.
7. `Counter`로 단어 빈도 상위 5개를 출력하세요.

## 출력 예시

```text
공백 기준 토큰:
['자연어', '처리는', '텍스트를', '분석하는', '기술입니다.', ...]

조사 제거 후 토큰:
['자연어', '처리', '텍스트', '분석하', '기술입니다', ...]

단어 빈도 상위 5개:
기술입니다: 3
문서: 2
자연어: 1
처리: 1
텍스트: 1
```

## 힌트

```python
for particle in particles:
    if token.endswith(particle):
        token = token[:-len(particle)]
        break
```
