## 문제

`data/sample_docs/day004.txt` 파일을 읽고 가장 자주 등장한 단어 상위 5개를 출력하세요.

## 요구사항

1. `days/day004_word_frequency/main.py`를 사용하세요.
2. 텍스트를 소문자로 정규화하세요.
3. 구두점을 제거하세요.
4. `split()`으로 단어 리스트를 만드세요.
5. `collections.Counter`를 사용하세요.
6. `most_common(5)`로 상위 5개 단어를 출력하세요.

## 입력 예시

```text
Python is useful.
Python is simple.
NLP is useful.
RAG uses search.
Search is important for RAG.
```

## 힌트

```python
from collections import Counter

counter = Counter(words)
top_words = counter.most_common(5)
```

## 완료 조건

- 단어 빈도가 계산된다.
- 상위 5개 단어가 빈도순으로 출력된다.
