## 문제

특정 폴더 안의 `.txt`, `.md` 파일을 모두 읽어 구조화된 문서 리스트로 반환하세요.

## 요구사항

1. `days/day023_document_loader/main.py`를 사용하세요.
2. `data/sample_docs/day023/` 폴더를 사용하세요.
3. 폴더 안의 `.txt`, `.md` 파일을 찾으세요.
4. 각 파일을 읽어 dictionary로 저장하세요.
5. dictionary에는 `source`, `filename`, `text`를 넣으세요.
6. 전체 문서 개수와 각 문서 정보를 출력하세요.

## 힌트

```python
for path in folder.glob("*.txt"):
    text = path.read_text(encoding="utf-8")
```

## 완료 조건

- 여러 문서가 리스트 형태로 로드된다.
