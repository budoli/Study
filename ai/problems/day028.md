## 문제

문서 로드, chunking, embedding, retrieve, answer 생성을 연결한 CLI Q&A 봇을 만드세요.

## 요구사항

1. `days/day028_cli_qa_bot/main.py`를 사용하세요.
2. 문서들을 로드하세요.
3. chunk와 metadata를 만드세요.
4. chunk를 임베딩하세요.
5. 사용자 질문을 `input()`으로 받으세요.
6. 관련 chunk Top 3를 검색하세요.
7. 템플릿 답변을 생성하세요.
8. 답변과 출처를 출력하세요.

## 힌트

```python
query = input("질문: ").strip()
results = retrieve(query, top_k=3)
answer = generate_answer(query, results)
```

## 완료 조건

- CLI에서 질문을 입력하면 답변과 출처가 출력된다.
