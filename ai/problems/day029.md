## 문제

RAG 검색/답변 로직을 FastAPI의 `/ask` API로 감싸세요.

## 요구사항

1. `days/day029_fastapi_ask/main.py`를 사용하세요.
2. `FastAPI` 앱을 만드세요.
3. Pydantic request model을 만드세요.
4. `POST /ask` 엔드포인트를 만드세요.
5. 요청으로 `question`을 받으세요.
6. 응답으로 `answer`, `sources`를 반환하세요.
7. `uvicorn`으로 실행 가능해야 합니다.

## 힌트

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class AskRequest(BaseModel):
    question: str

@app.post("/ask")
def ask(req: AskRequest):
    return {"answer": "...", "sources": []}
```

- `/ask`에 POST 요청을 보내면 JSON 응답이 반환된다.
