# Day 020 - chunk에 metadata 붙이기

| Day | 주제 | 문제명 | 핵심 |
| --- | --- | --- | --- |
| 020 | Metadata | 검색 결과에 출처 붙이기 | source, chunk_id |

## 문제

두 문서를 chunk로 나누고, 각 chunk에 출처 metadata를 dictionary로 붙이세요.

## 요구사항

1. `days/day020_metadata_sources/main.py`를 사용하세요.
2. `day020_doc1.txt`, `day020_doc2.txt`를 읽으세요.
3. `chunk_size = 80`, `overlap = 20`을 사용하세요.
4. 각 chunk를 dictionary로 저장하세요.
5. dictionary에는 `source`, `chunk_id`, `start`, `end`, `text`를 넣으세요.
6. 두 문서의 chunk를 하나의 리스트로 합치세요.
7. 전체 chunk 개수와 각 chunk 정보를 출력하세요.

## 힌트

```python
chunks.append({
    "source": path,
    "chunk_id": chunk_id,
    "start": start,
    "end": end,
    "text": chunk_text,
})
```

## 완료 조건

- 검색 결과에 출처를 붙일 수 있는 chunk 구조가 만들어진다.
