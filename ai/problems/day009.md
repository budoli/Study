## 문제

세 문서를 읽고 전체 단어 목록을 기준으로 각 문서를 Bag of Words 벡터로 표현하세요.

## 요구사항

1. `days/day009_bag_of_words/main.py`를 사용하세요.
2. 세 문서를 정규화된 토큰 리스트로 변환하세요.
3. 전체 문서의 고유 단어 목록 `vocabulary`를 만드세요.
4. `vocabulary`는 `sorted()`로 정렬하세요.
5. 각 문서를 `vocabulary` 기준 빈도 벡터로 변환하세요.
6. `vocabulary`와 문서별 BoW 벡터를 출력하세요.

## 힌트

```python
counter = Counter(tokens)
bow = [counter[word] for word in vocabulary]
```

## 완료 조건

- 모든 문서가 같은 vocabulary 기준의 숫자 벡터로 변환된다.
