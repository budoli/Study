# Day 010 - TF-IDF로 문서 키워드 뽑기

| --- | --- | --- | --- |
| 010 | TF-IDF | 문서 키워드 뽑기 | TfidfVectorizer |

## 문제

세 문서를 읽고 `TfidfVectorizer`로 각 문서의 중요 단어 상위 5개를 출력하세요.

## 요구사항

1. `days/day010_tfidf_keywords/main.py`를 사용하세요.
2. `TfidfVectorizer`를 import하세요.
3. 세 문서를 리스트로 읽으세요.
4. `fit_transform()`으로 TF-IDF 행렬을 만드세요.
5. `get_feature_names_out()`으로 단어 목록을 가져오세요.
6. 문서별 상위 5개 단어와 점수를 출력하세요.
7. 점수는 소수점 4자리로 출력하세요.

## 힌트

```python
vectorizer = TfidfVectorizer()
matrix = vectorizer.fit_transform(documents)
feature_names = vectorizer.get_feature_names_out()
```

## 완료 조건

- 각 문서별 TF-IDF 상위 5개 단어가 출력된다.
