## 문제

문장 5개를 `SentenceTransformer`로 임베딩하고 벡터 정보를 출력하세요.

## 요구사항

1. `days/day015_sentence_embedding/main.py`를 사용하세요.
2. `SentenceTransformer`를 import하세요.
3. 모델은 `sentence-transformers/all-MiniLM-L6-v2`를 사용하세요.
4. 문장 5개를 리스트로 작성하세요.
5. `model.encode(sentences)`로 임베딩하세요.
6. 임베딩 타입과 shape를 출력하세요.
7. 첫 번째 벡터 앞 10개 값을 출력하세요.
8. 각 문장별 벡터 길이를 출력하세요.

## 힌트

```python
model = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")
embeddings = model.encode(sentences)
```

## 완료 조건

- 임베딩 shape가 `(5, 384)` 형태로 출력된다.
