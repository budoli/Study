# Day 001 - 텍스트 파일 읽기

| Day | 주제 | 문제명 | 핵심 |
| --- | --- | --- | --- |
| 001 | 파일 처리 | 텍스트 파일 읽기 | Path, read_text |

## 문제

`data/sample_docs/day001.txt` 파일을 만들고, 그 안의 텍스트를 Python으로 읽어서 출력하세요.

NLP/RAG의 첫 단계는 모델을 사용하는 것이 아니라, 분석할 문서를 안정적으로 읽어오는 것입니다.

## 요구사항

1. `days/day001_text_file/main.py`를 사용하세요.
2. `pathlib.Path`를 사용해서 파일 경로를 다루세요.
3. `read_text(encoding="utf-8")`를 사용해서 텍스트 파일을 읽으세요.
4. 읽은 내용을 터미널에 그대로 출력하세요.
5. 파일이 없을 경우 에러 메시지를 출력하세요.

## 추천 폴더 구조

```text
ai/
  data/
    sample_docs/
      day001.txt
  days/
    day001_text_file/
      main.py
```

## day001.txt 예시

```text
NLP는 자연어 처리입니다.
RAG는 검색 증강 생성입니다.
오늘은 텍스트 파일을 읽는 연습을 합니다.
```

## 실행 예시

```powershell
python days/day001_text_file/main.py
```

## 출력 예시

```text
NLP는 자연어 처리입니다.
RAG는 검색 증강 생성입니다.
오늘은 텍스트 파일을 읽는 연습을 합니다.
```

## 힌트

```python
from pathlib import Path

file_path = Path("data/sample_docs/day001.txt")

if file_path.exists():
    text = file_path.read_text(encoding="utf-8")
    print(text)
else:
    print("파일을 찾을 수 없습니다.")
```

## 완료 조건

- `python days/day001_text_file/main.py`로 실행된다.
- `day001.txt` 내용이 그대로 출력된다.
- 파일이 없을 때 프로그램이 강제로 종료되지 않고 메시지를 출력한다.

## 핵심 포인트

- `Path()`는 파일 경로를 객체로 다루게 해준다.
- `exists()`는 파일이 실제로 있는지 확인한다.
- `read_text(encoding="utf-8")`는 텍스트 파일을 문자열로 읽는다.
- 한글 파일은 인코딩을 명시하는 습관이 좋다.
