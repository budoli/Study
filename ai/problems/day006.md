# Day 006 - 텍스트를 토큰으로 나누기

| Day | 주제 | 문제명 | 핵심 |
| --- | --- | --- | --- |
| 006 | 토큰화 | 텍스트를 토큰으로 나누기 | tokenization |

## 문제

`data/sample_docs/day006.txt` 파일을 읽고 기본 토큰, 정규화 토큰, 고유 토큰을 비교하세요.

## 요구사항

1. `days/day006_tokenization/main.py`를 사용하세요.
2. 원본 텍스트를 출력하세요.
3. `split()`으로 기본 토큰을 출력하세요.
4. 소문자 변환과 구두점 제거 후 정규화 토큰을 출력하세요.
5. 기본 토큰 개수와 정규화 토큰 개수를 출력하세요.
6. `set()`과 `sorted()`로 고유 토큰 목록을 출력하세요.
7. 고유 토큰 개수를 출력하세요.

## 입력 예시

```text
Python, Python, PYTHON!
NLP is text processing.
RAG is retrieval and generation.
Text processing is useful.
```

## 출력 예시

```text
기본 토큰:
['Python,', 'Python,', 'PYTHON!', 'NLP', 'is', 'text', 'processing.', 'RAG', 'is', 'retrieval', 'and', 'generation.', 'Text', 'processing', 'is', 'useful.']

정규화 토큰:
['python', 'python', 'python', 'nlp', 'is', 'text', 'processing', 'rag', 'is', 'retrieval', 'and', 'generation', 'text', 'processing', 'is', 'useful']

기본 토큰 개수: 16
정규화 토큰 개수: 16
고유 토큰 개수: 10
```

## 힌트

```python
basic_tokens = text.split()
normalized_tokens = normalized_text.split()
unique_tokens = sorted(set(normalized_tokens))
```

- 기본 토큰과 정규화 토큰의 차이를 확인한다.
- 고유 토큰 목록과 개수가 출력된다.
