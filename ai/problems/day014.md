## 문제

사용자가 입력한 검색어와 가장 가까운 문서를 찾아주는 CLI 검색기를 만드세요.

## 요구사항

1. `days/day014_search_cli/main.py`를 사용하세요.
2. 문서 3개를 읽으세요.
3. `input()`으로 검색어를 입력받으세요.
4. 빈 검색어면 `"검색어를 입력하세요."`를 출력하고 종료하세요.
5. 문서를 `fit_transform()`으로 벡터화하세요.
6. 검색어를 `transform([query])`으로 벡터화하세요.
7. `cosine_similarity()`로 유사도를 계산하세요.
8. 가장 유사한 문서를 출력하세요.

## 출력 예시

```text
검색어를 입력하세요: documents answers context

문서별 유사도:
문서 1: 0.0000
문서 2: 0.0000
문서 3: 0.5994

가장 유사한 문서:
문서 번호: 3
유사도: 0.5994
내용: RAG searches documents and generates answers using retrieved context.
```

## 힌트

```python
query = input("검색어를 입력하세요: ").strip()
query_vector = vectorizer.transform([query])
```

## 완료 조건

- CLI에서 검색어를 입력하면 관련 문서가 출력된다.
