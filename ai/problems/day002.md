# Day 002 - 문장과 단어 세기

| Day | 주제 | 문제명 | 핵심 |
| --- | --- | --- | --- |
| 002 | 문자열 | 문장과 단어 세기 | split, strip |

## 문제

`data/sample_docs/day002.txt` 파일을 읽고 줄 수, 빈 줄 제외 줄 수, 전체 단어 수, 줄별 단어 수를 출력하세요.

## 요구사항

1. `days/day002_count_text/main.py`를 사용하세요.
2. `Path`와 `read_text(encoding="utf-8")`를 사용하세요.
3. `splitlines()`로 줄을 나누세요.
4. `strip()`으로 빈 줄을 제외하세요.
5. `split()`으로 단어를 나누세요.
6. 전체 줄 수, 빈 줄 제외 줄 수, 전체 단어 수를 출력하세요.
7. 각 줄의 단어 수를 출력하세요.

## 입력 예시

```text
NLP는 자연어 처리입니다.
텍스트는 문장과 단어로 나눌 수 있습니다.

RAG는 검색한 문서를 바탕으로 답변을 생성합니다.
문서를 잘 나누는 것은 매우 중요합니다.
```

## 힌트

```python
lines = text.splitlines()
non_empty_lines = [line for line in lines if line.strip()]

for index, line in enumerate(non_empty_lines, start=1):
    words = line.split()
```

## 완료 조건

- 전체 줄 수가 출력된다.
- 빈 줄 제외 줄 수가 출력된다.
- 전체 단어 수가 출력된다.
- 줄별 단어 수가 출력된다.
