# Day 003 - 구두점 제거와 정규화

| Day | 주제 | 문제명 | 핵심 |
| --- | --- | --- | --- |
| 003 | 문자열 | 구두점 제거와 정규화 | lower, replace |

## 문제

`data/sample_docs/day003.txt` 파일을 읽고 텍스트를 정규화한 뒤, 정규화된 단어 리스트를 출력하세요.

## 요구사항

1. `days/day003_normalize_text/main.py`를 사용하세요.
2. 원본 텍스트를 출력하세요.
3. `lower()`로 소문자 변환을 하세요.
4. `replace()`로 `.`, `,`, `!`, `?`를 제거하세요.
5. 정규화된 텍스트를 출력하세요.
6. 정규화 전후 단어 수를 출력하세요.
7. 정규화된 단어 리스트를 출력하세요.

## 입력 예시

```text
Python is GREAT!
NLP, RAG, and Search are useful.
Text Cleaning is Important?
```

## 출력 예시

```text
원본 텍스트:
Python is GREAT!
NLP, RAG, and Search are useful.
Text Cleaning is Important?

정규화된 텍스트:
python is great
nlp rag and search are useful
text cleaning is important

정규화 전 단어 수: 13
정규화 후 단어 수: 13

정규화된 단어 리스트:
['python', 'is', 'great', 'nlp', 'rag', 'and', 'search', 'are', 'useful', 'text', 'cleaning', 'is', 'important']
```

## 힌트

```python
normalized_text = text.lower()
normalized_text = normalized_text.replace(".", "")
normalized_text = normalized_text.replace(",", "")
normalized_words = normalized_text.split()
```

## 완료 조건

- 대문자가 소문자로 바뀐다.
- 구두점이 제거된다.
- 정규화된 단어 리스트가 출력된다.
