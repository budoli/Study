# Day 026 - 답변 템플릿 만들기

| Day | 주제 | 문제명 | 핵심 |
| --- | --- | --- | --- |
| 026 | RAG | 답변 템플릿 만들기 | generator |

## 문제

LLM 호출 없이 검색된 context를 바탕으로 템플릿 답변을 생성하는 함수를 만드세요.

## 요구사항

1. `days/day026_answer_generator/main.py`를 사용하세요.
2. `generate_answer(query, results)` 함수를 만드세요.
3. 질문을 답변에 포함하세요.
4. 검색된 context 요약 형태를 답변에 포함하세요.
5. 검색 결과가 없으면 별도 메시지를 출력하세요.
6. 답변 문자열을 반환하고 출력하세요.

## 출력 예시

```text
질문:
RAG는 무엇인가요?

답변:
검색된 문서에 따르면, RAG는 외부 문서를 검색한 뒤 그 내용을 바탕으로 답변을 생성하는 방식입니다.
```

## 힌트

```python
if not results:
    return "관련 문서를 찾지 못했습니다."
```

## 완료 조건

- 검색 결과를 바탕으로 기본 답변 문자열이 만들어진다.
