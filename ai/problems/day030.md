# Day 030 - 문서 기반 RAG API 완성

| Day | 주제 | 문제명 | 핵심 |
| --- | --- | --- | --- |
| 030 | 종합 | 문서 기반 RAG API 완성 | FastAPI, RAG |

## 문제

30일 동안 만든 기능을 연결해 문서 기반 RAG API를 완성하세요.

## 요구사항

1. `days/day030_rag_api/main.py`를 사용하세요.
2. 문서 로더를 구현하세요.
3. chunking과 metadata 생성을 구현하세요.
4. 임베딩 기반 retriever를 구현하세요.
5. 답변 생성 함수를 구현하세요.
6. 출처 포함 응답을 만드세요.
7. `POST /ask` API를 만드세요.
8. README 또는 실행 방법 주석을 남기세요.

## API 응답 예시

```json
{
  "answer": "검색된 문서를 바탕으로 만든 답변입니다.",
  "sources": [
    {
      "source": "data/sample_docs/doc1.txt",
      "chunk_id": 1
    }
  ]
}
```

## 완료 조건

- 문서 읽기부터 API 응답까지 하나의 흐름으로 연결된다.
- 질문을 보내면 답변과 출처가 JSON으로 반환된다.
