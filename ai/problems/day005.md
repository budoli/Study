# Day 005 - 불용어 제거

| Day | 주제 | 문제명 | 핵심 |
| --- | --- | --- | --- |
| 005 | 전처리 | 불용어 제거 | stopwords |

## 문제

`data/sample_docs/day005.txt` 파일을 읽고 불용어를 제거한 뒤 남은 단어의 빈도 상위 5개를 출력하세요.

## 요구사항

1. `days/day005_stopwords/main.py`를 사용하세요.
2. 정규화 후 단어 리스트를 만드세요.
3. 직접 `stopwords` 집합을 만드세요.
4. 불용어 제거 전 단어 리스트를 출력하세요.
5. 불용어 제거 후 단어 리스트를 출력하세요.
6. 제거 후 단어 빈도 상위 5개를 출력하세요.

## 입력 예시

```text
Python is useful and simple.
NLP is useful for text analysis.
RAG is useful for search and question answering.
The search system is important for RAG.
```

## 출력 예시

```text
불용어 제거 전 단어 리스트:
['python', 'is', 'useful', 'and', 'simple', 'nlp', 'is', 'useful', 'for', 'text', 'analysis', 'rag', 'is', 'useful', 'for', 'search', 'and', 'question', 'answering', 'the', 'search', 'system', 'is', 'important', 'for', 'rag']

불용어 제거 후 단어 리스트:
['python', 'useful', 'simple', 'nlp', 'useful', 'text', 'analysis', 'rag', 'useful', 'search', 'question', 'answering', 'search', 'system', 'important', 'rag']

불용어 제거 후 단어 빈도 상위 5개:
useful: 3
rag: 2
search: 2
python: 1
simple: 1
```

## 힌트

```python
stopwords = {"is", "and", "for", "the"}
filtered_words = [word for word in words if word not in stopwords]
```

## 완료 조건

- `is`, `and`, `for`, `the`가 제거된다.
- 제거 후 빈도 상위 5개가 출력된다.
