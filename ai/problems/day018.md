| 018 | Chunking | 긴 문서 자르기 | chunk size |

## 문제

긴 텍스트 파일을 `chunk_size` 글자 단위로 나누어 chunk 리스트를 만드세요.

## 요구사항

1. `days/day018_chunking/main.py`를 사용하세요.
2. `data/sample_docs/day018.txt`를 읽으세요.
3. `chunk_size = 100`을 설정하세요.
4. `range(0, len(text), chunk_size)`를 사용하세요.
5. chunk 리스트를 만드세요.
6. 전체 chunk 개수를 출력하세요.
7. 각 chunk 번호, 실제 길이, 내용을 출력하세요.

## 힌트

```python
for start in range(0, len(text), chunk_size):
    end = start + chunk_size
    chunk = text[start:end]
```

## 완료 조건

- 마지막 chunk가 100보다 짧아도 정상 출력된다.
