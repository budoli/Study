## 문제

RAG 파이프라인을 역할별 함수로 나누어 구조를 잡으세요.

## 요구사항

1. `days/day022_rag_pipeline_structure/main.py`를 사용하세요.
2. `load_documents()` 함수를 만드세요.
3. `split_documents()` 함수를 만드세요.
4. `embed_chunks()` 함수를 만드세요.
5. `retrieve()` 함수를 만드세요.
6. `generate_answer()` 함수를 만드세요.
7. `main()`에서 전체 흐름을 순서대로 호출하세요.

## 힌트

```python
documents = load_documents()
chunks = split_documents(documents)
embeddings = embed_chunks(chunks)
results = retrieve(query, chunks, embeddings)
answer = generate_answer(query, results)
```

## 완료 조건

- 실제 구현이 단순해도 RAG 전체 흐름이 함수 단위로 분리된다.
