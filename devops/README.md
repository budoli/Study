## 최종 목표

30일 후에는 작은 백엔드 서비스를 기준으로 다음 흐름을 직접 설명하고 구현할 수 있어야 합니다.

```text
코드 작성
-> Git push
-> CI 테스트
-> Docker 이미지 빌드
-> 서버 또는 Kubernetes 배포
-> 로그/상태 확인
-> 장애 원인 파악
```

## 추천 학습 방식

- 하루 1~2시간 학습한다.
- 개념 30%, 실습 70% 비율로 진행한다.
- 매일 명령어와 결과를 짧게 기록한다.
- 모르는 명령어는 외우기보다 직접 실행하면서 익힌다.
- 최종 프로젝트는 `backend` 같은 기존 프로젝트를 활용해도 좋다.
