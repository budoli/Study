# Daily Coding Test Prep

하루에 한 문제씩 JavaScript, Java, Python으로 같은 문제를 풀며 코딩테스트 감각을 쌓는 연습장입니다.

## 진행 방식

1. `problems/day-XXX.md`의 문제를 먼저 읽습니다.
2. 20~40분 동안 한 언어로 직접 풉니다.
3. 같은 아이디어를 나머지 두 언어로 옮겨 봅니다.
4. 시간 복잡도와 엣지 케이스를 `notes.md`에 기록합니다.

## 추천 루틴

- 월~금: 새 문제 1개
- 토: 주간 복습 및 못 푼 문제 재도전
- 일: 쉬거나 이전 풀이 리팩터링

## 폴더 구조

```text
problems/       문제 설명
solutions/js/   JavaScript 풀이
solutions/java/ Java 풀이
solutions/python/ Python 풀이
notes.md        풀이 기록
roadmap.md      30일 학습 로드맵
```
