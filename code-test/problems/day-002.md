# Day 002 - 압축 문자열 길이

## 난이도

입문

## 문제

문자열 `s`가 주어집니다. 같은 문자가 연속해서 등장하면 문자와 등장 횟수로 압축했을 때의 문자열 길이를 반환하세요.

단, 문자가 한 번만 등장한 경우에는 횟수 `1`을 붙이지 않습니다.

## 입력 형식

- `s`: 길이가 1 이상 100,000 이하인 알파벳 소문자 문자열

## 출력 형식

- 압축한 문자열의 길이

## 예시

```text
s = "aaabbc"
compressed = "a3b2c"
return 5
```

```text
s = "abcd"
compressed = "abcd"
return 4
```

```text
s = "aaaaaaaaaa"
compressed = "a10"
return 3
```

```text
s = "aabbaa"
compressed = "a2b2a2"
return 6
```

## 제한

- 문자열을 실제로 만들어도 되지만, 길이만 계산하는 방식도 가능합니다.
- 시간 복잡도 `O(n)` 풀이를 목표로 하세요.

## 힌트

현재 문자와 이전 문자가 같은지 비교하면서 연속 개수를 세어보세요.

## 체크 포인트

- 마지막 문자 그룹을 처리했는가?
- 개수가 1일 때 숫자를 붙이지 않았는가?
- 개수가 10 이상일 때 자리수를 정확히 더했는가?
