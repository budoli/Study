# Day 005 - 올바른 괄호 확장판

## 난이도

입문

## 문제

문자열 `s`가 주어집니다. 문자열에는 괄호 문자 `()`, `{}`, `[]`만 등장합니다.

모든 괄호가 올바르게 열리고 닫혔다면 `true`를 반환하고, 그렇지 않다면 `false`를 반환하세요.

## 입력 형식

- `s`: 길이가 1 이상 100,000 이하인 문자열
- `s`는 `(`, `)`, `{`, `}`, `[`, `]`로만 이루어져 있습니다.

## 출력 형식

- 올바른 괄호 문자열이면 `true`
- 올바르지 않으면 `false`

## 예시

```text
s = "()[]{}"
return true
```

```text
s = "([{}])"
return true
```

```text
s = "(]"
return false
```

```text
s = "([)]"
return false
```

```text
s = "((("
return false
```

## 제한

- 열린 괄호는 같은 종류의 닫힌 괄호로 닫혀야 합니다.
- 열린 괄호는 올바른 순서로 닫혀야 합니다.
- 시간 복잡도 `O(n)` 풀이를 목표로 하세요.

## 힌트

가장 최근에 열린 괄호가 가장 먼저 닫혀야 합니다.

이 구조는 `Stack`과 잘 맞습니다.

## 체크 포인트

- 닫는 괄호가 나왔을 때 스택이 비어 있는 경우를 처리했는가?
- 닫는 괄호가 나왔을 때 가장 최근 열린 괄호와 짝이 맞는가?
- 모든 문자를 처리한 뒤 스택이 비어 있는가?
