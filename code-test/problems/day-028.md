# Day 028 - 작업 순서 정하기

## 문제

작업 개수 `n`과 선행 관계 `relations`가 주어집니다.

각 관계 `[a, b]`는 작업 `a`를 먼저 해야 작업 `b`를 할 수 있다는 뜻입니다.

가능한 작업 순서 하나를 반환하세요. 모든 작업을 완료할 수 없으면 빈 배열을 반환하세요.

## 예시

```text
n = 4
relations = [[1, 2], [1, 3], [3, 4]]
return [1, 2, 3, 4]
```

다른 가능한 순서도 정답입니다.

## 힌트

위상 정렬을 사용하세요.

```text
진입 차수가 0인 작업을 큐에 넣는다.
큐에서 꺼내 결과에 넣고, 연결된 작업의 진입 차수를 줄인다.
```

## 체크 포인트

- 결과 길이가 n보다 작으면 사이클이 있다는 뜻입니다.
