# Day 015 - 계단 오르기

## 문제

정수 `n`이 주어집니다. 한 번에 1칸 또는 2칸을 오를 수 있을 때, 정확히 `n`칸을 오르는 방법의 수를 반환하세요.

답이 커질 수 있으므로 `1,000,000,007`로 나눈 나머지를 반환하세요.

## 입력

- `n`: 1 이상 100,000 이하인 정수

## 출력

- 계단을 오르는 방법의 수

## 예시

```text
n = 4
return 5
```

## 힌트

마지막에 1칸을 올라왔거나, 2칸을 올라왔을 수 있습니다.

```text
dp[i] = dp[i - 1] + dp[i - 2]
```
