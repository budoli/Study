# Day 024 - N개의 수 고르기

## 문제

정수 `n`과 `m`이 주어집니다.

1부터 `n`까지의 수 중에서 중복 없이 `m`개를 고르는 모든 조합을 반환하세요.

각 조합은 오름차순이어야 하며, 전체 결과도 사전순으로 정렬되어야 합니다.

## 예시

```text
n = 4
m = 2
return [[1, 2], [1, 3], [1, 4], [2, 3], [2, 4], [3, 4]]
```

## 힌트

백트래킹에서 `start` 값을 넘기면 이전에 고른 수보다 큰 수만 선택할 수 있습니다.

```text
dfs(start)
```
