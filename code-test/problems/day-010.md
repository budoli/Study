# Day 010 - 의상 조합 수

## 난이도

입문

## 문제

의상 정보가 담긴 2차원 문자열 배열 `clothes`가 주어집니다.

각 의상은 `[name, type]` 형태입니다.

- `name`: 의상 이름
- `type`: 의상 종류

하루에 같은 종류의 의상은 최대 하나만 입을 수 있습니다.

단, 아무 의상도 입지 않는 경우는 제외합니다.

서로 다른 의상 조합의 개수를 반환하세요.

## 입력 형식

- `clothes`: 길이가 1 이상 30 이하인 2차원 문자열 배열
- 각 원소는 `[name, type]`
- 같은 이름을 가진 의상은 없습니다.

## 출력 형식

- 가능한 의상 조합의 개수

## 예시

```text
clothes = [
  ["yellow_hat", "headgear"],
  ["blue_sunglasses", "eyewear"],
  ["green_turban", "headgear"]
]
return 5
```

설명:

```text
headgear는 2개, eyewear는 1개입니다.

headgear 선택 방법: yellow_hat, green_turban, 선택 안 함 -> 3가지
eyewear 선택 방법: blue_sunglasses, 선택 안 함 -> 2가지

전체 경우의 수 = 3 * 2 = 6
아무것도 입지 않는 경우 1개 제외
정답 = 5
```

```text
clothes = [
  ["crow_mask", "face"],
  ["blue_sunglasses", "face"],
  ["smoky_makeup", "face"]
]
return 3
```

설명:

```text
face 종류에서 하나를 선택하는 경우만 가능합니다.
정답은 3입니다.
```

## 제한

- 같은 종류에서는 하나만 선택할 수 있습니다.
- 종류별로 선택하지 않는 경우도 고려해야 합니다.
- 전체 조합에서 아무것도 선택하지 않는 1가지는 제외해야 합니다.

## 힌트

먼저 의상 종류별 개수를 세어보세요.

종류별 의상 개수가 `count`개라면, 그 종류에서 가능한 선택지는 다음과 같습니다.

```text
count개 중 하나 선택 + 선택 안 함
= count + 1가지
```

모든 종류의 선택지를 곱한 뒤, 아무것도 선택하지 않는 경우 1개를 빼면 됩니다.
