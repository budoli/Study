# Day 003 - 연속 부분합 최대값

## 난이도

입문

## 문제

정수 배열 `numbers`가 주어집니다. 이 배열에서 하나 이상의 연속된 원소를 선택했을 때 만들 수 있는 부분합 중 가장 큰 값을 반환하세요.

## 입력 형식

- `numbers`: 길이가 1 이상 100,000 이하인 정수 배열

## 출력 형식

- 연속 부분합의 최대값

## 예시

```text
numbers = [1, -3, 2, 5, -1]
return 7
```

설명:

```text
[2, 5]를 선택하면 합이 7입니다.
```

```text
numbers = [-5, -2, -8]
return -2
```

설명:

```text
모든 수가 음수이면 가장 큰 원소 하나를 선택해야 합니다.
```

```text
numbers = [4, -1, 2, 1]
return 6
```

설명:

```text
[4, -1, 2, 1] 전체를 선택하면 합이 6입니다.
```

## 제한

- 반드시 하나 이상의 원소를 선택해야 합니다.
- 시간 복잡도 `O(n)` 풀이를 목표로 하세요.
- 모든 연속 구간을 직접 구하면 `O(n^2)`가 되어 시간 초과가 날 수 있습니다.

## 힌트

현재 위치에서 선택할 수 있는 최선은 두 가지입니다.

```text
1. 이전까지의 연속합에 현재 값을 이어 붙인다.
2. 현재 값부터 새로 시작한다.
```

둘 중 더 큰 값을 현재 위치의 최선으로 보면 됩니다.

## 체크 포인트

- 모든 값이 음수인 경우에도 동작하는가?
- `0`이 포함된 배열에서도 동작하는가?
- 빈 구간을 선택하지 않았는가?
