# Day 027 - 가장 긴 증가 부분수열

## 문제

정수 배열 `numbers`가 주어집니다. 원소의 순서를 유지하면서 일부 원소를 골랐을 때, 값이 strictly increasing인 부분수열의 최대 길이를 반환하세요.

## 예시

```text
numbers = [10, 20, 10, 30, 20, 50]
return 4
```

설명:

```text
[10, 20, 30, 50]
```

## 힌트

입문 풀이로는 `dp[i] = i번째 원소로 끝나는 LIS 길이`를 사용할 수 있습니다.

```text
if numbers[j] < numbers[i]:
    dp[i] = max(dp[i], dp[j] + 1)
```

## 목표

- O(n^2) 풀이부터 정확히 구현하세요.
