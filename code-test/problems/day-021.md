# Day 021 - 트리 순회 결과

## 문제

이진 트리의 노드 정보 `nodes`가 주어집니다.

각 원소는 `[value, left, right]` 형태입니다.

- `value`: 현재 노드 값
- `left`: 왼쪽 자식 값, 없으면 `-1`
- `right`: 오른쪽 자식 값, 없으면 `-1`

루트 노드는 항상 `1`입니다.

전위 순회 결과와 중위 순회 결과를 2차원 배열로 반환하세요.

```text
return [preorder, inorder]
```

## 예시

```text
nodes = [
  [1, 2, 3],
  [2, 4, -1],
  [3, -1, -1],
  [4, -1, -1]
]
return [[1, 2, 4, 3], [4, 2, 1, 3]]
```

## 힌트

노드 값을 key로 하고 `[left, right]`를 value로 하는 Map/dict를 만들면 순회하기 쉽습니다.
