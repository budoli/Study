# Day 026 - 로봇 청소기

## 문제

방 크기 `n x m`, 방 상태 `room`, 시작 위치 `(r, c)`, 시작 방향 `d`가 주어집니다.

- `0`: 청소하지 않은 빈 칸
- `1`: 벽
- `2`: 이미 청소한 칸

로봇은 다음 규칙으로 움직입니다.

1. 현재 칸이 청소되지 않은 빈 칸이면 청소합니다.
2. 현재 칸의 주변 4칸 중 청소되지 않은 빈 칸이 있으면, 왼쪽으로 회전하며 갈 수 있는 칸을 찾아 전진합니다.
3. 주변 4칸에 청소할 칸이 없으면, 바라보는 방향을 유지한 채 한 칸 후진합니다.
4. 후진할 칸이 벽이면 작동을 멈춥니다.

청소한 칸의 개수를 반환하세요.

## 방향

```text
0: 북, 1: 동, 2: 남, 3: 서
```

## 힌트

시뮬레이션 문제입니다. 방향 배열과 회전 규칙을 정확히 구현하세요.
