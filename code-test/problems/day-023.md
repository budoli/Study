# Day 023 - 친구 그룹

## 문제

학생 수 `n`과 친구 관계 `relations`가 주어집니다.

친구 관계는 서로 연결되는 관계입니다. 직접 친구가 아니어도 친구의 친구라면 같은 그룹입니다.

전체 친구 그룹의 개수를 반환하세요.

## 예시

```text
n = 5
relations = [[1, 2], [2, 3], [4, 5]]
return 2
```

## 힌트

Union-Find를 사용하세요.

```text
find(x): x가 속한 대표 그룹 찾기
union(a, b): a와 b를 같은 그룹으로 합치기
```

모든 관계를 합친 뒤 대표 노드의 개수를 세면 됩니다.
