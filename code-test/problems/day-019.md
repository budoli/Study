# Day 019 - 구간 합 질의

## 문제

정수 배열 `numbers`와 여러 질의 `queries`가 주어집니다.

각 질의는 `[left, right]` 형태이며, `numbers[left]`부터 `numbers[right]`까지의 합을 구해야 합니다.

모든 질의의 답을 배열로 반환하세요.

## 입력

- `numbers`: 길이 1 이상 100,000 이하
- `queries`: 길이 1 이상 100,000 이하

## 출력

- 각 구간 합을 담은 배열

## 예시

```text
numbers = [1, 2, 3, 4, 5]
queries = [[0, 2], [1, 3], [2, 4]]
return [6, 9, 12]
```

## 힌트

누적합 배열을 만들면 각 질의를 O(1)에 처리할 수 있습니다.

```text
prefix[i + 1] = prefix[i] + numbers[i]
sum(left, right) = prefix[right + 1] - prefix[left]
```
