# Day 011 - 연결 요소 개수

## 난이도

입문

## 문제

정점 개수 `n`과 간선 정보 `edges`가 주어집니다.

정점은 `1`번부터 `n`번까지 번호가 붙어 있습니다.

무방향 그래프에서 서로 연결된 정점들의 묶음을 `연결 요소`라고 할 때, 전체 연결 요소의 개수를 반환하세요.

## 입력 형식

- `n`: 1 이상 100,000 이하인 정수
- `edges`: 길이가 0 이상 200,000 이하인 2차원 정수 배열
- 각 원소는 `[a, b]` 형태이며, 정점 `a`와 정점 `b`가 서로 연결되어 있음을 의미합니다.
- `1 <= a, b <= n`
- 자기 자신으로 연결되는 간선은 없습니다.

## 출력 형식

- 연결 요소의 개수

## 예시

```text
n = 5
edges = [[1, 2], [2, 3], [4, 5]]
return 2
```

설명:

```text
1-2-3이 하나의 연결 요소이고, 4-5가 다른 연결 요소입니다.
```

```text
n = 5
edges = [[1, 2], [2, 3], [3, 4], [4, 5]]
return 1
```

```text
n = 4
edges = []
return 4
```

설명:

```text
간선이 없으면 각 정점이 하나의 연결 요소입니다.
```

## 제한

- 그래프는 무방향입니다.
- 모든 정점이 연결되어 있다는 보장이 없습니다.
- 시간 복잡도 `O(n + e)` 풀이를 목표로 하세요.
- `e`는 간선 개수입니다.

## 힌트

아직 방문하지 않은 정점을 발견하면 연결 요소 하나를 찾은 것입니다.

그 정점에서 DFS 또는 BFS를 시작해서 연결된 모든 정점을 방문 처리하세요.

## 체크 포인트

- 무방향 그래프이므로 양쪽 방향으로 간선을 추가했는가?
- 1번부터 n번까지 모든 정점을 확인했는가?
- 방문하지 않은 정점을 만날 때마다 answer를 증가시켰는가?
