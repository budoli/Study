# Day 004 - 회의실 배정

## 난이도

입문

## 문제

회의 시간이 담긴 2차원 배열 `meetings`가 주어집니다. 각 회의는 `[start, end]` 형태이며, `start`는 시작 시간, `end`는 종료 시간입니다.

한 회의실에서 서로 겹치지 않게 진행할 수 있는 회의의 최대 개수를 반환하세요.

회의가 끝나는 시간과 다음 회의가 시작하는 시간이 같으면, 두 회의는 겹치지 않는 것으로 봅니다.

## 입력 형식

- `meetings`: 길이가 1 이상 100,000 이하인 2차원 정수 배열
- 각 원소는 `[start, end]`
- `0 <= start <= end <= 1,000,000`

## 출력 형식

- 한 회의실에서 진행할 수 있는 회의의 최대 개수

## 예시

```text
meetings = [[1, 4], [2, 3], [3, 5], [4, 6]]
return 2
```

설명:

```text
[2, 3]과 [3, 5]를 선택할 수 있습니다.
또는 [1, 4]와 [4, 6]도 선택할 수 있습니다.
```

```text
meetings = [[1, 2], [2, 3], [3, 4]]
return 3
```

```text
meetings = [[5, 7], [1, 3], [2, 6], [3, 4]]
return 3
```

설명:

```text
[1, 3], [3, 4], [5, 7]을 선택할 수 있습니다.
```

## 제한

- 회의는 한 번 선택하면 시작부터 끝까지 사용해야 합니다.
- 한 번에 하나의 회의만 진행할 수 있습니다.
- 시간 복잡도 `O(n log n)` 풀이를 목표로 하세요.

## 힌트

가장 빨리 끝나는 회의를 먼저 선택하면, 남은 시간에 더 많은 회의를 넣을 가능성이 커집니다.

## 체크 포인트

- 종료 시간이 빠른 순서로 정렬했는가?
- 종료 시간이 같다면 시작 시간이 빠른 순서로 정렬했는가?
- `start >= lastEnd` 조건으로 다음 회의를 선택했는가?
