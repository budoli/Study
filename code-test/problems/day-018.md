# Day 018 - 파일명 정렬

## 문제

파일명 배열 `files`가 주어집니다. 각 파일명은 `HEAD`, `NUMBER`, `TAIL`로 나눌 수 있습니다.

- `HEAD`: 숫자가 나오기 전까지의 문자열
- `NUMBER`: 처음 등장하는 연속 숫자, 최대 5자리
- `TAIL`: 그 뒤 나머지 문자열

다음 기준으로 파일명을 정렬한 배열을 반환하세요.

1. `HEAD`를 대소문자 구분 없이 사전순 정렬
2. `HEAD`가 같으면 `NUMBER`를 숫자값 기준 오름차순 정렬
3. 둘 다 같으면 원래 입력 순서 유지

## 예시

```text
files = ["img12.png", "img10.png", "img02.png", "img1.png"]
return ["img1.png", "img02.png", "img10.png", "img12.png"]
```

## 힌트

정렬 전에 파일명을 파싱해서 `head`, `number`, `index`를 함께 저장하세요.

## 체크 포인트

- HEAD 비교 시 소문자/대문자 차이를 무시했는가?
- NUMBER를 문자열이 아니라 숫자로 비교했는가?
- 안정 정렬 또는 원래 index를 활용했는가?
