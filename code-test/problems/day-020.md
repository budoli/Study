# Day 020 - 최대 매출 구간

## 문제

일별 매출 배열 `sales`와 기간 `k`가 주어집니다.

연속된 `k`일 동안의 매출 합 중 최댓값을 반환하세요.

## 입력

- `sales`: 길이 1 이상 100,000 이하인 정수 배열
- `k`: 1 이상 `sales.length` 이하

## 출력

- 연속된 `k`개 원소의 최대 합

## 예시

```text
sales = [5, 3, 8, 2, 10, 1]
k = 3
return 20
```

설명:

```text
[8, 2, 10]의 합이 20으로 가장 큽니다.
```

## 힌트

처음 `k`개의 합을 만든 뒤, 오른쪽 값을 더하고 왼쪽 값을 빼며 창을 한 칸씩 이동하세요.
