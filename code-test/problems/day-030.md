# Day 030 - 배송 경로 최적화

## 문제

물류 지점 수 `n`, 도로 정보 `roads`, 출발지 `start`, 배송지 목록 `targets`가 주어집니다.

각 도로는 `[a, b, cost]` 형태이며 양방향입니다.

출발지에서 모든 배송지까지의 최단 거리 합을 반환하세요. 하나라도 도달할 수 없는 배송지가 있으면 `-1`을 반환하세요.

## 예시

```text
n = 5
roads = [[1, 2, 2], [1, 3, 5], [2, 3, 1], [2, 4, 2], [3, 5, 3]]
start = 1
targets = [4, 5]
return 8
```

설명:

```text
1 -> 4 최단 거리: 4
1 -> 5 최단 거리: 4
합계: 8
```

## 힌트

출발지 하나에서 여러 배송지까지의 최단 거리를 구해야 하므로, `start`에서 다익스트라를 한 번 실행하면 됩니다.
