# Day 014 - 더 맵게

## 문제

음식의 매운 정도가 담긴 배열 `scoville`과 목표 매운 정도 `k`가 주어집니다.

가장 맵지 않은 음식 두 개를 섞어 새 음식을 만들 수 있습니다.

```text
새 음식 = 가장 맵지 않은 음식 + 두 번째로 맵지 않은 음식 * 2
```

모든 음식의 매운 정도가 `k` 이상이 되기 위한 최소 섞기 횟수를 반환하세요. 불가능하면 `-1`을 반환하세요.

## 입력

- `scoville`: 길이 1 이상 1,000,000 이하인 정수 배열
- `k`: 목표 매운 정도

## 출력

- 최소 섞기 횟수

## 예시

```text
scoville = [1, 2, 3, 9, 10, 12]
k = 7
return 2
```

## 힌트

매번 가장 작은 값 두 개를 빠르게 꺼내야 하므로 최소 힙을 사용하세요.

## 체크 포인트

- 가장 작은 값이 이미 `k` 이상이면 종료했는가?
- 힙에 음식이 1개만 남았는데도 `k` 미만이면 `-1`을 반환했는가?
