# Day 025 - 부분집합 합

## 문제

정수 배열 `numbers`와 목표값 `target`이 주어집니다.

`numbers`의 원소 중 일부를 선택했을 때 합이 `target`이 되는 부분집합이 존재하면 `true`, 없으면 `false`를 반환하세요.

빈 부분집합은 선택할 수 없습니다.

## 예시

```text
numbers = [3, 1, 7, 5]
target = 8
return true
```

설명:

```text
3 + 5 = 8
```

## 힌트

원소 개수가 작다면 비트마스크로 모든 부분집합을 만들 수 있습니다.

```text
mask의 각 비트가 원소 선택 여부
```

## 제한

- `numbers.length <= 20`
