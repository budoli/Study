# Day 007 - 피로도 던전

## 난이도

입문

## 문제

현재 피로도 `k`와 던전 정보가 담긴 2차원 배열 `dungeons`가 주어집니다.

각 던전은 `[required, cost]` 형태입니다.

- `required`: 던전에 입장하기 위해 필요한 최소 피로도
- `cost`: 던전을 클리어한 뒤 소모되는 피로도

하루에 각 던전은 최대 한 번만 방문할 수 있습니다.

현재 피로도로 탐험할 수 있는 던전의 최대 개수를 반환하세요.

## 입력 형식

- `k`: 1 이상 5,000 이하인 정수
- `dungeons`: 길이가 1 이상 8 이하인 2차원 정수 배열
- 각 원소는 `[required, cost]`
- `1 <= cost <= required <= 1,000`

## 출력 형식

- 탐험할 수 있는 던전의 최대 개수

## 예시

```text
k = 80
dungeons = [[80, 20], [50, 40], [30, 10]]
return 3
```

설명:

```text
[80, 20] -> [30, 10] -> [50, 40] 순서로는 불가능합니다.
하지만 [80, 20] -> [50, 40] -> [30, 10] 순서로는 3개를 모두 탐험할 수 있습니다.
```

```text
k = 40
dungeons = [[40, 20], [30, 10], [20, 20]]
return 2
```

## 제한

- 던전 방문 순서에 따라 결과가 달라질 수 있습니다.
- 단순히 `required`가 큰 순서나 `cost`가 작은 순서로 정렬하면 항상 정답이 되지 않습니다.
- 던전 수가 최대 8개이므로 모든 방문 순서를 탐색할 수 있습니다.

## 힌트

현재 갈 수 있는 던전을 하나 선택하고, 피로도를 소모한 뒤 다음 던전을 다시 선택해보세요.

이 과정을 재귀적으로 반복하면 됩니다.

## 체크 포인트

- 이미 방문한 던전을 다시 방문하지 않는가?
- 현재 피로도가 `required` 이상일 때만 입장하는가?
- 탐색 중 얻은 최대 방문 개수를 계속 갱신하는가?
