# Day 022 - 네트워크 전파 시간

## 문제

방향 그래프의 간선 정보 `times`, 정점 수 `n`, 시작 정점 `start`가 주어집니다.

각 간선은 `[from, to, cost]` 형태입니다. `start`에서 모든 정점으로 신호가 퍼지는 데 걸리는 최소 시간을 반환하세요.

모든 정점에 도달할 수 없으면 `-1`을 반환하세요.

## 예시

```text
n = 4
times = [[2, 1, 1], [2, 3, 1], [3, 4, 1]]
start = 2
return 2
```

## 힌트

가중치가 있는 그래프의 최단 거리는 다익스트라 알고리즘을 사용합니다. 우선순위 큐에 `[거리, 정점]`을 넣어 관리하세요.

## 체크 포인트

- 방향 그래프이므로 한쪽 방향만 추가했는가?
- 더 짧은 거리를 발견했을 때만 갱신했는가?
- 도달하지 못한 정점이 있는지 확인했는가?
