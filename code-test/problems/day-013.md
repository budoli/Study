# Day 013 - 섬의 개수

## 문제

`0`과 `1`로 이루어진 2차원 배열 `grid`가 주어집니다.

- `1`: 땅
- `0`: 바다

상하좌우로 연결된 땅은 하나의 섬입니다. 전체 섬의 개수를 반환하세요.

## 입력

- `grid`: `n x m` 정수 배열
- `1 <= n, m <= 100`

## 출력

- 섬의 개수

## 예시

```text
grid = [
  [1, 1, 0, 0],
  [1, 0, 0, 1],
  [0, 0, 1, 1]
]
return 2
```

## 힌트

방문하지 않은 땅을 만나면 섬 하나를 발견한 것입니다. 그 위치에서 DFS/BFS로 연결된 모든 땅을 방문 처리하세요.

## 체크 포인트

- 상하좌우 네 방향만 확인했는가?
- 이미 방문한 땅을 다시 세지 않았는가?
- 격자 범위를 벗어나지 않도록 처리했는가?
