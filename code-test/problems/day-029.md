# Day 029 - 자동완성 최소 입력

## 문제

서로 다른 단어 배열 `words`가 주어집니다.

각 단어를 다른 단어와 구분하기 위해 최소 몇 글자를 입력해야 하는지 계산하고, 모든 단어의 최소 입력 글자 수 합을 반환하세요.

## 예시

```text
words = ["go", "gone", "guild"]
return 7
```

설명:

```text
go: 2글자
gone: 3글자
guild: 2글자
총 7
```

## 힌트

Trie에 단어를 넣으며 각 노드에 그 prefix를 공유하는 단어 개수를 저장하세요.

단어를 다시 탐색하면서 count가 1이 되는 순간까지의 길이가 최소 입력 길이입니다.
