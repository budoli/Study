# Day 008 - 합이 K인 연속 구간

## 난이도

입문

## 문제

양의 정수 배열 `numbers`와 정수 `k`가 주어집니다.

`numbers`에서 합이 정확히 `k`가 되는 연속 구간의 개수를 반환하세요.

## 입력 형식

- `numbers`: 길이가 1 이상 100,000 이하인 양의 정수 배열
- 각 원소는 1 이상 10,000 이하입니다.
- `k`: 1 이상 1,000,000 이하인 정수

## 출력 형식

- 합이 `k`가 되는 연속 구간의 개수

## 예시

```text
numbers = [1, 2, 1, 3, 2]
k = 3
return 3
```

설명:

```text
[1, 2], [2, 1], [3] 총 3개입니다.
```

```text
numbers = [1, 1, 1, 1]
k = 2
return 3
```

설명:

```text
[1, 1] 구간이 총 3개입니다.
```

```text
numbers = [2, 4, 6]
k = 5
return 0
```

## 제한

- 배열의 모든 원소는 양수입니다.
- 시간 복잡도 `O(n)` 풀이를 목표로 하세요.
- 모든 시작점과 끝점을 직접 확인하면 `O(n^2)`가 되어 시간 초과가 날 수 있습니다.

## 힌트

모든 숫자가 양수이기 때문에 구간의 오른쪽 끝을 늘리면 합은 커지고, 왼쪽 끝을 줄이면 합은 작아집니다.

이 성질을 이용해 `left`, `right` 두 포인터와 `sum`을 관리해보세요.

## 체크 포인트

- 현재 합이 `k`보다 크면 왼쪽 값을 빼고 `left`를 이동했는가?
- 현재 합이 `k`와 같을 때 개수를 증가시켰는가?
- 같은 원소를 여러 번 더하거나 빼지 않았는가?
