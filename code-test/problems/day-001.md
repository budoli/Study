# Day 001 - 두 수의 합 인덱스

## 난이도

입문

## 문제

정수 배열 `numbers`와 정수 `target`이 주어집니다. 서로 다른 두 원소의 합이 `target`이 되는 두 인덱스를 찾아 오름차순 배열로 반환하세요.

정답은 정확히 하나만 존재한다고 가정합니다.

## 입력 형식

- `numbers`: 길이가 2 이상 100,000 이하인 정수 배열
- `target`: 정수

## 출력 형식

- 합이 `target`이 되는 두 원소의 인덱스 `[i, j]`
- 항상 `i < j`가 되도록 반환

## 예시

```text
numbers = [2, 7, 11, 15]
target = 9
return [0, 1]
```

```text
numbers = [3, 2, 4]
target = 6
return [1, 2]
```

```text
numbers = [-1, -3, 4, 8]
target = 5
return [1, 3]
```

## 제한

- 같은 인덱스를 두 번 사용할 수 없습니다.
- 중복된 숫자가 있을 수 있습니다.
- 시간 복잡도 `O(n)` 풀이를 목표로 하세요.

## 힌트

지금 보고 있는 숫자 `x`에 대해, 이전에 `target - x`가 등장했는지 빠르게 확인할 수 있는 자료구조를 생각해 보세요.
