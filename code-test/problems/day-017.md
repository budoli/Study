# Day 017 - 가장 긴 팰린드롬

## 문제

문자열 `s`가 주어집니다. `s`의 부분 문자열 중 가장 긴 팰린드롬의 길이를 반환하세요.

팰린드롬은 앞에서 읽어도 뒤에서 읽어도 같은 문자열입니다.

## 입력

- `s`: 길이 1 이상 2,000 이하인 문자열

## 출력

- 가장 긴 팰린드롬 부분 문자열의 길이

## 예시

```text
s = "babad"
return 3
```

```text
s = "cbbd"
return 2
```

## 힌트

각 위치를 중심으로 좌우로 확장해보세요. 홀수 길이와 짝수 길이 팰린드롬을 모두 확인해야 합니다.
